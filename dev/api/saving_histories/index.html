Saving histories

What a simulation or a fitted session saves of each model, chosen by name, and whether it saves where the models started, as timestep 0.

  • CognitiveModeling.SaveEverything
  • CognitiveModeling.SaveHistory
CognitiveModeling.SaveEverything — Type
SaveEverything()

Marker for saving every attribute of a kind, used in SaveHistory.

source
CognitiveModeling.SaveHistory — Type
SaveHistory(; states=(), inputs=(), outputs=(), output_distributions=(),
            save_initial_values=true)
SaveHistory(SaveEverything(); save_initial_values=true)

Which states, inputs, outputs and output distributions of a model a simulation or a fitted session saves, by name, and whether it saves them from before the first timestep too.

states, inputs, outputs and output_distributions are each the names of that kind to save, in a Tuple of Symbols, a single Symbol or a Vector of them, or SaveEverything for all of them. The names are the model's own, as attribute_names lists them: for a cognitive model the inputs are its observations and the outputs its actions, and for an environment model the inputs are the actions it receives and the outputs the observations it gives. The output distributions are what the model gave its outputs to be sampled from, named like the outputs. A kind that isn't given saves nothing, so SaveHistory() saves nothing, which is the default everywhere, and SaveHistory(SaveEverything()) saves everything. The selections are read as properties, such as save_history.states.

save_initial_values is whether what is saved starts with timestep 0, before the first timestep: the initial states, and the previous input and output, which are BeforeFirstTimestep unless others are given. It is true by default, which matters when the initial state depends on parameters that are fitted. Since Julia counts from 1, element t + 1 of what is saved is then timestep t, and with false, element t is.

Saving some names of a kind gives a NamedTuple with those names on each timestep, which only works when the value is a NamedTuple, and saving none gives an empty one, (;), for any value. Before the first timestep there is no output distribution, so timestep 0 has BeforeFirstTimestep() for each name that is saved.

Each model of a simulation has one: simulate and SessionInfo take cognitive_save_history and environment_save_history, and an InstantiatedModel takes save_history. The trajectories that a simulation or a session returns are named by their role: the cognitive model's inputs as observations and outputs as actions, and the environment's inputs as actions and outputs as observations under environment, as simulate describes.

Examples

julia> save_history = SaveHistory(; outputs = :choice, states = (:expected_reward, :surprise))
SaveHistory
States: expected_reward, surprise
Inputs: none
Outputs: choice
Output distributions: none
Initial values: saved

julia> save_history.states
(:expected_reward, :surprise)

julia> SaveHistory(SaveEverything()).inputs
SaveEverything()

julia> SaveHistory(SaveEverything(); save_initial_values = false).save_initial_values
false
