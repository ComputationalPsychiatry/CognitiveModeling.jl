CognitiveModeling.BeforeFirstTimestep — Type
BeforeFirstTimestep()

Stand-in for an observation or an action from before the first timestep, when there is none yet, as one entry of a NamedTuple, such as (; choice = BeforeFirstTimestep()).

A cognitive model receives it for every previous action on its first timestep, and for every observation too when the agent starts. An environment model receives it for every previous observation on its first timestep, and for every action too when the environment starts. NoObservation and NoAction are different: they say that nothing was observed or done on a timestep that did run.

Before the first timestep is timestep 0, which a simulation, a history and a fitted session start with when their SaveHistory saves the initial values, as it does by default. Its observation and action are this marker unless others are given, and so is its size.

CognitiveModeling.Deterministic — Type
Deterministic(value)

An action or an observation that is always value, for a cognitive model or an environment model which gives it without any randomness, as in (; reward = Deterministic(1.0)).

A simulation samples every action and every observation with rand, and sampling from a Deterministic gives value itself. The value is kept in the field value.

A simulation throws an error for a number, a string or a symbol that isn't wrapped, since none of them is something to sample from. A vector, a tuple or a range that isn't wrapped is sampled from as it is, which is rarely what is meant: rand picks one of its elements, with no error.

Examples

julia> using Random: Xoshiro

julia> rand(Xoshiro(1), Deterministic(1.0))
1.0

julia> ModelOutput((; choice = Deterministic(true))).action_distribution.choice.value
true

CognitiveModeling.InvalidParametersError — Type
InvalidParametersError(message)
InvalidParametersError()

An error for a model to throw from apply_model or initialize_state when its parameters aren't valid, as in throw(InvalidParametersError()).

The default message says that the parameters are not valid, possibly dependent on the observations, actions and states, and a model can give a more specific one. A simulation stops with it as with any other error, and fitting can catch it to give the parameters a probability of zero, so a model should throw this rather than an ordinary error when the parameters are the problem.

Examples

julia> try
           throw(InvalidParametersError())
       catch error
           sprint(showerror, error)
       end
"InvalidParametersError: Model parameters are not valid, possibly dependent on observations, actions and states."

julia> sprint(showerror, InvalidParametersError("The learning rate must be between 0 and 1."))
"InvalidParametersError: The learning rate must be between 0 and 1."

CognitiveModeling.ModelInput — Type
ModelInput(observation, previous_state, previous_action, parameters, timestep_size=1,
           rng=default_rng())

Everything a model needs to run a single timestep, which apply_model receives.

Each argument is kept in a field of the same name, such as input.observation.

Arguments

  • observation: what the model observes on this timestep, in a NamedTuple with the names the environment gave them, as in input.observation.reward. An observation that isn't made on this timestep is NoObservation. On the first timestep when the agent starts, every observation is BeforeFirstTimestep.
  • previous_state: the state of the model after the previous timestep. On the first timestep, this is the output of initialize_state.
  • previous_action: the actions from the previous timestep, in a NamedTuple with the names the model gave them, as in input.previous_action.choice. On the first timestep, each of them is BeforeFirstTimestep.
  • parameters: the cognitive parameters of the model. Will generally be a NamedTuple.
  • timestep_size=1: how much time this timestep covers.
  • rng=default_rng(): the random number generator to sample from if anything in the model is random, so that a simulation can be reproduced.

Examples

julia> observation = (; reward = 1.0);

julia> state = (; expected_reward = 0.5);

julia> parameters = (; learning_rate = 0.1);

julia> previous_action = (; choice = BeforeFirstTimestep());

julia> ModelInput(observation, state, previous_action, parameters).timestep_size
1

julia> ModelInput(observation, state, previous_action, parameters, 0.5).timestep_size
0.5

CognitiveModeling.ModelOutput — Type
ModelOutput(action_distribution, new_state=(;))

The outputs of a model for a single timestep, which apply_model returns.

Each argument is kept in a field of the same name, such as output.new_state.

Arguments

  • action_distribution::NamedTuple: what the actions on this timestep are sampled from, in a NamedTuple with one entry for each action, such as (; choice = Bernoulli(0.7)). Each entry can be anything that works with rand, such as a distribution from Distributions.jl, or a Deterministic for an action that isn't random, and the sampled actions keep the names. An action that isn't taken on this timestep is NoAction, and a model without actions gives an empty NamedTuple, (;).
  • new_state=(;): the cognitive state of the model after this timestep, which is the previous_state of the next one.

julia> ModelOutput((; choice = NoAction(), bet = Bernoulli(0.2))).action_distribution.choice

CognitiveModeling.CommonRLEnvironment — Type
CommonRLEnvironment(rl_env; action_name)

An environment model around rl_env, an environment from CommonRLInterface.jl, which needs CommonRLInterface.jl to be loaded. action_name is the name of the cognitive model's action that act! receives, such as :arm.

Environments from POMDPs.jl and ReinforcementLearning.jl can be used through it, with convert(CommonRLInterface.AbstractEnv, x), which POMDPTools.jl defines for a POMDP or MDP and ReinforcementLearningBase.jl for its environments.

rl_env itself is the state: initialize_state resets it with CommonRLInterface.jl's reset! and returns it, every timestep changes it in place with act! and passes it on as the new state, and prepare_state_for_saving copies it, with clone if it provides it and with deepcopy otherwise. A method of prepare_state_for_saving for a CommonRLEnvironment with a specific type of rl_env can save something lighter. The parameters aren't used, and neither is the random number generator, since an environment of CommonRLInterface.jl has its own randomness.

Each observation is a NamedTuple (; observation, reward, terminated): what observe gives, the reward that act! returned, and whether the episode has ended. They are given as they are, each in a Deterministic, so nothing more is sampled. Before the first action, when the action is BeforeFirstTimestep, the environment is at its initial observation, so the reward is NoObservation and nothing is done with the action. The same goes for a timestep where the model takes no action, NoAction: the environment stays where it is. Its attribute_names are these three observations, the one action, no parameters and no states, since rl_env isn't a NamedTuple. Use EnvironmentStarts, so that the model observes before it acts.

A simulation stops by itself when the episode ends, since the stopping_criterion of the environment is terminated of rl_env, so n_steps is the most timesteps it can take. An episode that has ended isn't started again, and an action given to it throws an error. A new call of simulate starts a new episode, and so does reset! of an Environment, since both reset rl_env through initialize_state.

Examples

using CognitiveModeling
using CommonRLInterface

#A two-armed bandit where the first arm always pays, in episodes of two pulls
mutable struct Bandit <: CommonRLInterface.AbstractEnv
    pulls::Int
end
CommonRLInterface.reset!(rl_env::Bandit) = (rl_env.pulls = 0; nothing)
CommonRLInterface.actions(rl_env::Bandit) = 1:2
CommonRLInterface.observe(rl_env::Bandit) = rl_env.pulls
CommonRLInterface.act!(rl_env::Bandit, arm) = (rl_env.pulls += 1; arm == 1 ? 1.0 : 0.0)
CommonRLInterface.terminated(rl_env::Bandit) = rl_env.pulls == 2

#A model which always pulls the first arm
struct PullsFirstArm <: AbstractCognitiveModel end
CognitiveModeling.initialize_state(model::PullsFirstArm, parameters) = (;)
CognitiveModeling.apply_model(model::PullsFirstArm, input::ModelInput) = ModelOutput((; arm = Deterministic(1)))
CognitiveModeling.attribute_names(model::PullsFirstArm) = ModelAttributes(; parameters = (), states = (), observations = (:observation, :reward, :terminated), actions = :arm)

#The simulation stops when the episode ends, before it has run all of n_steps
observations, actions, _, _, _ = simulate(
    PullsFirstArm(),
    CommonRLEnvironment(Bandit(0); action_name = :arm);
    who_starts = EnvironmentStarts(),
    n_steps = 10,
    cognitive_parameters = (;),
    environment_parameters = (;),
    save_history = SaveHistory(SaveEverything()),
)

#Timestep 0, before the first timestep, and then what the environment gave on each timestep
foreach(println, observations)

# output

(observation = BeforeFirstTimestep(), reward = BeforeFirstTimestep(), terminated = BeforeFirstTimestep())
(observation = 0, reward = NoObservation(), terminated = false)
(observation = 1, reward = 1.0, terminated = false)
(observation = 2, reward = 1.0, terminated = true)

CognitiveModeling.SaveHistory — Type
SaveHistory(; observations=(), actions=(), states=(), save_initial_values=true)
SaveHistory(SaveEverything(); save_initial_values=true)

Which observations, actions and states a simulation saves, by name, and whether it saves them from before the first timestep too.

observations, actions and states are each the names of that kind to save, in a Tuple of Symbols, a single Symbol or a Vector of them, or SaveEverything for all of them. A kind that isn't given saves nothing, so SaveHistory() saves nothing, which is the default everywhere, and SaveHistory(SaveEverything()) saves everything. The selections are kept in the type, so that selecting costs nothing in a simulation, and are read as properties, such as save_history.states.

save_initial_values is whether what is saved starts with timestep 0, before the first timestep: the initial states, and the previous observation and action, which are BeforeFirstTimestep unless others are given. It is true by default, which matters when the initial state depends on parameters that are fitted. Since Julia counts from 1, element t + 1 of what is saved is then timestep t, and with false, element t is.

Saving some names of a kind gives a NamedTuple with those names on each timestep, which only works when the value is a NamedTuple, and saving none gives an empty one, (;), for any value. For an environment, the states are its own, and the observations and actions are those it gave and received, which are the agent's unless a NameMap selects or renames them. simulate! adds them to the environment's history too, while simulate only uses its states.

See also CognitiveAgent, Environment and simulate, which take one.

Examples

julia> save_history = SaveHistory(; actions = :choice, states = (:expected_reward, :surprise))
SaveHistory
Observations: none
Actions: choice
States: expected_reward, surprise
Initial values: saved

julia> save_history.states
(:expected_reward, :surprise)

julia> SaveHistory(SaveEverything()).observations
SaveEverything()

julia> SaveHistory(SaveEverything(); save_initial_values = false).save_initial_values
false

CognitiveModeling.AgentHistory — Type
AgentHistory(observations, actions, states, timestep_sizes)

The history of states, actions and observations for a CognitiveAgent, which simulate! adds to.

Each argument is kept in a field of the same name, such as history.actions. The agent's SaveHistory selects what is kept of each observation, action and state, and when it selects nothing at all, the vectors stay empty. Each vector starts with timestep 0, where the agent started, when the SaveHistory saves the initial values, which it does by default, so that element t + 1 is timestep t.

Arguments

  • observations::Vector{Any}: the observations, starting at timestep 0 with one where every observation the model lists is BeforeFirstTimestep.
  • actions::Vector{Any}: the actions, starting at timestep 0 with the agent's previous action, which by default has every action as BeforeFirstTimestep().
  • states::Vector{Any}: the states of the model, starting at timestep 0 with its initial state. Later states are those after each timestep. All of them are as returned by prepare_state_for_saving.
  • timestep_sizes::Vector{Any}: how much time each timestep covered, starting with BeforeFirstTimestep() for timestep 0, so that it has an entry for each entry of the other vectors.

CognitiveModeling.CognitiveAgent — Type
CognitiveAgent(cognitive_model, cognitive_parameters; save_history=SaveHistory())
CognitiveAgent(cognitive_model, cognitive_parameters, cognitive_state, previous_action;
               save_history=SaveHistory())

An instantiated cognitive model with its parameters, current state, and previous action, which simulate! can update iteratively.

Each argument is kept in a field of the same name, such as agent.cognitive_state. Parameters that aren't given take the values in default_parameters, if the model provides defaults for them. CognitiveModeling.NameMap — Type
NameMap(names...)

Which outputs of one side of a simulation the other side receives, and under which names.

Each argument is :given => :received, for an output which the receiver lists under another name, or a single Symbol, for one which keeps its name. Outputs that aren't in the map aren't passed on, and each name can only be there once. The names are kept in the type, so that a map costs nothing in a simulation.

simulate and simulate! take one as observation_map, from the observations the environment model gives to those the cognitive model lists, and one as action_map, from the actions the cognitive model gives to those the environment model lists. A cognitive model and an environment which name things differently, or where one gives something the other doesn't list, can then be used together, and the map says which outputs the receiver gets: it must give exactly the names the receiver lists in attribute_names. NameMap() passes nothing on, for a receiver which lists nothing. Without a map, the two must list the same names.

CognitiveModeling.reset! — Function
reset!(agent::CognitiveAgent)
reset!(environment::Environment)

Put agent or environment back to where a new one starts, and return it.

The state becomes the output of initialize_state with the parameters it has. The previous action of an agent has every action as BeforeFirstTimestep again, and so has every observation of the previous observation of an environment. The history is a new one which starts from there, as timestep 0 when the SaveHistory saves the initial values, so a history that was read before the reset, as in history = agent.history, is kept as it was. The model, the parameters and the SaveHistory stay the same.

An agent or an environment that was created with a state, a previous action or a previous observation of its own doesn't return to those. Create a new one for that.

Examples

using CognitiveModeling
using Distributions: Bernoulli

struct RescorlaWagner <: AbstractCognitiveModel end

function CognitiveModeling.initialize_state(model::RescorlaWagner, parameters)
    return (; expected_reward = 0.5)
end

function CognitiveModeling.apply_model(model::RescorlaWagner, input::ModelInput)
    V₋₁ = input.previous_state.expected_reward
    Vₜ = V₋₁ + input.parameters.learning_rate * (input.observation.reward - V₋₁)
    return ModelOutput((; choice = Bernoulli(Vₜ)), (; expected_reward = Vₜ))
end

function CognitiveModeling.attribute_names(model::RescorlaWagner)
    return ModelAttributes(; parameters = :learning_rate, states = :expected_reward, observations = :reward, actions = :choice)
end

agent = CognitiveAgent(RescorlaWagner(), (; learning_rate = 0.5); save_history = SaveHistory(SaveEverything()))

simulate!(agent, (; reward = 1.0))
simulate!(agent, (; reward = 1.0))
reset!(agent)

agent.cognitive_state, agent.previous_action, agent.history.states

# output

((expected_reward = 0.5,), (choice = BeforeFirstTimestep(),), Any[(expected_reward = 0.5,)])

CognitiveModeling.simulate! — Method
simulate!(agent::CognitiveAgent, observation; timestep_size=1, rng=default_rng())

Run a single timestep of agent on observation, update it, and return the sampled action. What agent.save_history selects of the observation, the action and the state is added to agent.history, together with the size of the timestep.

The action is in a NamedTuple with the name the model gave it, as in action.choice, as for simulate. The observation must be a NamedTuple with every observation the model lists in attribute_names, or an ArgumentError is thrown.

Arguments

  • agent::CognitiveAgent: the agent to update.
  • observation::NamedTuple: what the agent observes on this timestep, such as (; reward = 1.0). An observation that isn't made is NoObservation.
  • timestep_size=1: how much time this timestep covers.
  • rng::AbstractRNG=default_rng(): the random number generator to sample from.

CognitiveModeling.simulate! — Method
simulate!(agent::CognitiveAgent, environment::Environment; <keyword arguments>)

Simulate agent interacting with environment from where they are, update them both, and return the same as simulate, without timestep 0: the vectors with what agent.save_history selects of the observations, actions and states on each timestep of this call, and what environment.save_history selects of the environment's states, followed by the sizes of the timesteps. What the two select is also added to agent.history and environment.history, together with the sizes of the timesteps, unless a selection is empty. A history has timestep 0 from where the agent or the environment started, when its SaveHistory saves the initial values.

The agent's model and the environment's must fit together, as for simulate, directly or through observation_map and action_map. The agent's history holds the observations as its model received them, and the environment's history the actions as its model did.

The simulation ends before n_steps timesteps if stopping_criterion of the environment's model is met. An environment where it is met already can't be simulated further, and throws an error until it is reset!.

Reading the agent's untyped fields costs a dynamic dispatch on each call, which makes the return type unknown to the compiler. The loop inside is still fully typed. Use simulate if the return type matters, or if most calls are for a single timestep.

Arguments

  • who_starts::Union{AgentStarts, EnvironmentStarts}: who moves first on each timestep.
  • n_steps::Int: the number of timesteps to simulate, which must be at least 1. It is the most timesteps there can be when the environment's model has a stopping_criterion.
  • timestep_sizes=1: how much time each timestep covers. A value that isn't a vector, such as a single number, is the size of every timestep of this call. A vector has one size for each timestep of this call, so its length must be n_steps.
  • rng::AbstractRNG=default_rng(): the random number generator to sample from.
  • observation_map::Union{Nothing, NameMap}=nothing: which observations of the environment the agent receives, and under which names, as for simulate.
  • action_map::Union{Nothing, NameMap}=nothing: which actions of the agent the environment receives, and under which names, as for simulate.

CognitiveModeling.simulate — Method
simulate(cognitive_model, environment; <keyword arguments>)

Simulate cognitive_model interacting with environment, and return the vectors observations, actions, cognitive_states and environment_states, with one element for timestep 0, before the first timestep, and one for each timestep after it, followed by timestep_sizes.

Each element is what happened on that timestep, and the states are those after it. The element for timestep 0 has the previous observation and action, which are BeforeFirstTimestep unless others are given, and the states before the first timestep. Since Julia counts from 1, element t + 1 is timestep t. save_history and save_environment_history select what is kept of each element, which is nothing by default: give SaveHistory(SaveEverything()) to keep everything, and SaveHistory(SaveEverything(); save_initial_values = false) to leave out timestep 0, so that element t is timestep t. The sizes of the timesteps are returned as they were given: a single size as it is, and a vector of sizes with the sizes of the timesteps that ran, after BeforeFirstTimestep() for timestep 0 when it is there.

Parameters that aren't given take the values in default_parameters, if cognitive_model or environment provides defaults for them. The names of the parameters, the states, the previous action and the previous observation must be those in attribute_names, and cognitive_model and environment must list the same observations and the same actions, or an ArgumentError is thrown before the first timestep. When the two name things differently, or one gives something the other doesn't list, observation_map and action_map say which outputs of one the other receives, and under which names. The observations are then returned as cognitive_model received them, and the actions as it gave them.

The simulation ends before n_steps timesteps if stopping_criterion of environment is met, and everything returned then has the timesteps that ran.

Arguments

  • cognitive_model::AbstractCognitiveModel: the cognitive model.
  • environment::AbstractEnvironmentModel: the environment model.
  • who_starts::Union{AgentStarts, EnvironmentStarts}: who moves first on each timestep. It has no default, because a wrong choice shifts the model by a timestep without any error.
  • n_steps::Int: the number of timesteps to simulate, which must be at least 1. It is the most timesteps there can be when environment has a stopping_criterion.
  • timestep_sizes=1: how much time each timestep covers, which both cognitive_model and environment receive. A value that isn't a vector, such as a single number, is the size of every timestep. A vector has one size for each timestep, so its length must be n_steps.
  • cognitive_parameters::NamedTuple: the parameters of cognitive_model, with its default values for those that aren't given, if it provides any.
  • environment_parameters::NamedTuple: the parameters of environment, with its default values for those that aren't given, if it provides any.
  • rng::AbstractRNG=default_rng(): the random number generator to sample actions and observations from, which cognitive_model and environment also receive in their inputs.
  • previous_cognitive_state=initialize_state(cognitive_model, ...): the state of cognitive_model before the first timestep, by default its initial state from the full parameters. A state that cognitive_model changes in place will be changed.
  • previous_action=initial_action(cognitive_model): the action before the first timestep. By default every action is BeforeFirstTimestep, with the names from attribute_names.
  • previous_environment_state=initialize_state(environment, ...): the state of environment before the first timestep, by default its initial state from the full parameters.
  • previous_observation=initial_observation(environment): the observation before the first timestep. By default every observation is BeforeFirstTimestep(), with the names from attribute_names of environment.
  • save_history::SaveHistory=SaveHistory(): which observations, actions and states of cognitive_model are saved, by name, and whether timestep 0 is. Nothing is saved by default, and SaveHistory(SaveEverything()) saves everything. See SaveHistory.
  • save_environment_history::SaveHistory=SaveHistory(): which states of environment are saved. Only its states is used here, since the observations and actions are returned once, as save_history selects them, and so that the four vectors have the same length, save_history decides whether they start with timestep 0.
  • observation_map::Union{Nothing, NameMap}=nothing: which observations of environment are passed on to cognitive_model, and under which names, as a NameMap from the names environment gives to exactly those cognitive_model lists. Without one, the two must list the same observations, which cognitive_model receives under the same names.
  • action_map::Union{Nothing, NameMap}=nothing: which actions of cognitive_model are passed on to environment, and under which names, as a NameMap from the names cognitive_model gives to exactly those environment lists. Without one, the two must list the same actions, which environment receives under the same names.

See also simulate!, which continues from where the last simulation ended.

Extended help

The return type is concrete as long as the types of the outputs don't change between timesteps. If they do, like an observation with an entry that is sometimes NoObservation, the vector for that output holds a Union of the types, and the simulation is a little slower. The same goes for timestep 0 when it has other types than the timesteps after it, which the observations and actions usually do, since they are BeforeFirstTimestep() there.

Nothing is copied when outputs are saved. A model or environment which changes an object in its state in place, instead of returning a new one, must add a method of prepare_state_for_saving, or all the saved states show the final values, with no error. Observations and actions have no such function, so they must be new objects on each timestep.

CognitiveModeling.simulate — Method
simulate(cognitive_model, observation; <keyword arguments>)

Run a single timestep of cognitive_model on observation, without an environment, and return the sampled action and the new state of the model.

Nothing is kept between calls, so pass the returned state and action on as previous_cognitive_state and previous_action to run the next timestep. simulate! on a single observation does the same for a CognitiveAgent, which keeps them. The compiler knows the types here, which it doesn't for an agent, so this is the faster of the two.

  • timestep_size=1: how much time this timestep covers.

CognitiveModeling.turing_single_session — Function
turing_single_session(cognitive_model, cognitive_parameters, observations, actions;
                      <keyword arguments>)

Create a Turing.jl model of one session: cognitive_model with cognitive_parameters goes through the timesteps of the data, and the recorded actions are scored against the action distributions it gives. This needs Turing.jl to be loaded.

The model is a building block for a Turing.jl model which samples the parameters, as a submodel with its own prefix: to_submodel(prefix(turing_single_session(...), @varname(session)), false). It returns what save_history selects of the observations, the actions and the states of the session, as a NamedTuple of vectors with one element for timestep 0, before the first timestep, and one for each timestep after it, which returned(model, chain) gives for each sample. Timestep 0 has the previous observation and action, which are BeforeFirstTimestep unless others are given, and the initial state, which can depend on the parameters. Element t + 1 is then timestep t, and a SaveHistory with save_initial_values = false leaves timestep 0 out. Its timestep_sizes has the size of each timestep, after BeforeFirstTimestep() for timestep 0 when it is there, when anything is selected, and is empty otherwise. Nothing is selected by default.

On each timestep, turing_apply_model of cognitive_model runs as a submodel with the prefix timestep[t], so a model which samples within a timestep has its own variables for each timestep, such as timestep[3].noise. The recorded actions are scored together at the end, in one product_distribution over every action and timestep, which is several times faster than scoring each timestep on its own.

Arguments

  • cognitive_model::AbstractCognitiveModel: the cognitive model.
  • cognitive_parameters::NamedTuple: its parameters, usually the random variables of the model around this one. Those it doesn't have take the values in default_parameters, if the model provides defaults for them.
  • observations::NamedTuple: the observations in the data, with one vector for each name and one entry for each timestep, such as (; reward = [1.0, 0.0, 1.0]). The data must have every observation the model lists in attribute_names, and can have more. An observation that wasn't recorded is MissingObservation, which environment fills in.
  • actions::NamedTuple: the actions in the data, in the same form, with exactly the actions the model lists. An action that was taken but not recorded is MissingAction, and is imputed unless impute_missing_actions is false. An action that wasn't taken is NoAction, and isn't scored.
  • who_starts::Union{AgentStarts, EnvironmentStarts}: whether the model acts on the observation of the same timestep, EnvironmentStarts(), or on the observation of the timestep before, AgentStarts(), as in simulate. It has no default, because a wrong choice shifts the model by a timestep without any error.
  • environment::Union{Nothing, AbstractEnvironmentModel}=nothing: an environment model which fills in the observations that are MissingObservation(). When it is given, it runs on every timestep as a submodel with the prefix timestep[t].environment, and what it gives for an observation is only used where the data has none: the missing observation is then imputed from it, as a latent variable with that distribution, or as the value itself if it is a Deterministic. Its turing_apply_model must sample with ~ if anything else in it is random. It must list the same observations and the same actions as cognitive_model, since a session takes no maps of names. Without it, the data can't have missing observations.
  • environment_parameters::NamedTuple=(;): the parameters of environment, with its default values for those that aren't given, if it provides any.
  • timestep_sizes=1: how much time each timestep covers, as in simulate.
  • impute_missing_actions::Bool=true: whether an action that is MissingAction() is imputed, as a latent variable. When it is false, nothing is sampled for it, and it is passed on as NoAction() instead: cognitive_model receives NoAction() as that previous action on the next timestep, and environment as the action it responds to.
  • save_history::SaveHistory=SaveHistory(): which observations, actions and states are returned, by name, and whether timestep 0 is. The returned actions and observations are those the model received, with the imputed and filled in values.
  • catch_invalid_parameters::Bool=false: whether an InvalidParametersError from the model gives the parameters a log density of -Inf, so that a sampler rejects them, instead of stopping the sampler. It is off by default because the try block it needs can't be differentiated with Mooncake, and a compiled ReverseDiff tape doesn't see the error, so the parameters get a finite log density with no warning. It works with ForwardDiff and Enzyme.
  • previous_cognitive_state, previous_action, previous_observation, previous_environment_state: where the session starts, with the same defaults as in simulate.

An imputed action is a latent variable named after its timestep and action, such as timestep[3].choice.imputed, with the model's action distribution on that timestep as its distribution. An observation imputed from a distribution is one in the same way, under the environment's prefix, such as timestep[3].environment.reward.imputed. The sampler must handle its type: a continuous action can be sampled with NUTS, a discrete one needs a sampler for discrete variables. Any latent variable in a session, imputed or from a model which samples within a timestep, makes evaluating the model much slower in the current version of DynamicPPL.jl.

CognitiveModeling.apply_model — Method
apply_model(model::AbstractCognitiveModel, input::ModelInput)::ModelOutput

Run a single timestep of model. Usually this involves updating cognitive states and returning an object from which the action is sampled.

Implementation

    #Reward observed on this timestep
    r = input.observation.reward
    #Expected reward from the previous state

end

A cognitive model or an environment model can add a method of this function. The default returns state as it is, so nothing is copied. One which changes an object in its state in place must add a method which copies it, or all the saved states show the final values, with no error.

CognitiveModeling.turing_apply_model — Function
turing_apply_model(model::AbstractCognitiveModel, input::ModelInput)
turing_apply_model(environment::AbstractEnvironmentModel, input::EnvironmentInput)

Create a Turing.jl model for a single timestep of model, to be used as a submodel, which returns a ModelOutput, or of environment, which returns an EnvironmentOutput. This needs Turing.jl to be loaded.

Implementation

A model can add a method of this function. The default calls apply_model. A model which samples within a timestep needs to add a method, however; or if any other changes are desired within Turing. It must sample with ~ instead of from input.rng. Otherwise the model has a different log density each time it is evaluated, with no error. The same holds for an environment model, which fitting uses to fill in observations that are MissingObservation in the data: what it samples itself, such as a change of its state, must be sampled with ~, while fitting samples the observations from what it returns.

Examples

using CognitiveModeling
using Turing

struct NoisyRescorlaWagner <: AbstractCognitiveModel end

Turing.@model function CognitiveModeling.turing_apply_model(
        model::NoisyRescorlaWagner,
        input::ModelInput,
    )

    ## Unpack input ##
    #Reward observed on this timestep
    r = input.observation.reward
    #Expected reward from the previous state
    V₋₁ = input.previous_state.expected_reward
    #Learning rate parameter
    α = input.parameters.learning_rate

    ## Update state ##
    #Sample the noise in the update
    ϵ ~ Normal(0, input.parameters.noise)
    #Update expected reward using the Rescorla-Wagner rule
    Vₜ = V₋₁ + α * (r - V₋₁) + ϵ

    return ModelOutput((; choice = BernoulliLogit(Vₜ - 0.5)), (; expected_reward = Vₜ))
end

CognitiveModeling.stopping_criterion — Function
stopping_criterion(environment::AbstractEnvironmentModel, state, parameters)

Return whether environment has ended, with state as its state after a timestep and its parameters, so that a simulation stops there instead of running all of n_steps.

simulate and simulate! check it before each timestep, with the state that the timestep before left. When it returns true, no further timestep runs, and what is returned and added to the histories has the timesteps that ran. When the environment starts, the cognitive model has then made its last observation and acted on it, and the environment doesn't receive that action. An environment whose criterion is already met before the first timestep can't be simulated, and throws an error: a new simulation starts from the initial state, and reset! puts an Environment back there.

Implementation

An environment model can add a method of this function. The default returns false, so a simulation runs all of its timesteps.

Examples

julia> struct Maze <: AbstractEnvironmentModel end

julia> function CognitiveModeling.stopping_criterion(environment::Maze, state, parameters)
           return state.position == parameters.goal
       end;

julia> CognitiveModeling.stopping_criterion(Maze(), (; position = 4), (; goal = 4))
true
