API

What users work with, by topic:

  • Defining models: the types that a cognitive model or an environment model is written with, and the functions it implements.
  • Simulation: running models, alone or together.
  • Saving histories: what a simulation or a fitted session saves of each model.
  • Fitting: the sessions to fit, how the parameters of several sessions are given, and what runs after them.
  • Fitting with Turing.jl: the Turing.jl models of the sessions, and reading the trajectories they saved from a chain.

The functions and types that are only used inside the package are under Internals.
