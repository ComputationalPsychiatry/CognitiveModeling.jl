Supertype for cognitive models.

Implementation

CognitiveModeling.AbstractEnvironmentModel — Type
AbstractEnvironmentModel

Supertype for environment models, which give a cognitive model its observations.

Implementation

Create a subtype and add a method of apply_model for it, which takes an EnvironmentInput and returns an EnvironmentOutput. An environment model with a state also adds a method of initialize_state.

See also simulate, which has an example.

CognitiveModeling.AgentStarts — Type
AgentStarts()

Make the agent move first on each timestep of a simulation.

On a timestep, the cognitive model updates and acts on the previous observation, and the environment then responds to its action. On the first timestep, the cognitive model receives NoObservation.

See also EnvironmentStarts, simulate.

CognitiveModeling.simulate! — Method
simulate!(agent::CognitiveAgent, environment::Environment; <keyword arguments>)

Simulate agent interacting with environment from where they are, update them both, and return the same vectors as simulate.

Use the same who_starts on each call, so that each simulation continues the last one.

Reading the agent's untyped fields costs a dynamic dispatch on each call, which makes the return type unknown to the compiler. The loop inside is still fully typed. Use simulate if the return type matters, or if most calls are for a single timestep.

Arguments

  • who_starts::Union{AgentStarts, EnvironmentStarts}: who moves first on each timestep.
  • n_steps::Int: the number of timesteps to simulate, which must be at least 1.
  • timestep_sizes=1: how much time each timestep covers. A vector has one size for each timestep of this call, so its length must be n_steps.
  • rng::AbstractRNG=default_rng(): the random number generator to sample from.

Examples

using CognitiveModeling
using CognitiveModeling: ModelInput, ModelOutput, EnvironmentInput, EnvironmentOutput
using Distributions: Bernoulli

struct RandomChoices <: AbstractCognitiveModel end

function CognitiveModeling.apply_model(model::RandomChoices, input::ModelInput)
    return ModelOutput(Bernoulli(0.5))
end

struct TimestepCounter <: AbstractEnvironmentModel end

function CognitiveModeling.initialize_state(model::TimestepCounter, parameters)
    return (; n_timesteps = 0)
end

function CognitiveModeling.apply_model(model::TimestepCounter, input::EnvironmentInput)
    n_timesteps = input.previous_state.n_timesteps + 1
    return EnvironmentOutput((; n_timesteps), (; n_timesteps))
end

agent = CognitiveAgent(RandomChoices(), (;))
environment = Environment(TimestepCounter(), (;))

simulate!(agent, environment; who_starts = EnvironmentStarts(), n_steps = 2)
simulate!(agent, environment; who_starts = EnvironmentStarts(), n_steps = 3)

environment.state

# output

(n_timesteps = 5,)

CognitiveModeling.simulate — Method
simulate(model, environment; <keyword arguments>)

Simulate model interacting with environment, and return the vectors observations, actions, cognitive_states and environment_states, with one element for each timestep.

Each element is what happened on that timestep, and the states are those after it.

Arguments

  • model::AbstractCognitiveModel: the cognitive model.
  • environment::AbstractEnvironmentModel: the environment model.
  • who_starts::Union{AgentStarts, EnvironmentStarts}: who moves first on each timestep. It has no default, because a wrong choice shifts the model by a timestep without any error.
  • n_steps::Int: the number of timesteps to simulate, which must be at least 1.
  • timestep_sizes=1: how much time each timestep covers, which both model and environment receive. A vector has one size for each timestep, so its length must be n_steps. Anything else is the size of every timestep.
  • cognitive_parameters::NamedTuple: the parameters of model.
  • environment_parameters::NamedTuple: the parameters of environment.
  • rng::AbstractRNG=default_rng(): the random number generator to sample actions from, which model and environment also receive in their inputs.
  • previous_state=initialize_state(model, cognitive_parameters): the state of model before the first timestep. A state that model changes in place will be changed.
  • previous_action=NoAction(): the action before the first timestep.
  • previous_environment_state=initialize_state(environment, environment_parameters): the state of environment before the first timestep.
  • previous_observation=NoObservation(): the observation before the first timestep.

See also simulate!, which continues from where the last simulation ended.

Examples

using CognitiveModeling
using CognitiveModeling: ModelInput, ModelOutput, EnvironmentInput, EnvironmentOutput
using Distributions: BernoulliLogit

#A cognitive model which learns the expected reward
struct RescorlaWagner <: AbstractCognitiveModel end

function CognitiveModeling.initialize_state(model::RescorlaWagner, parameters)
    return (; expected_reward = 0.5)
end

function CognitiveModeling.apply_model(model::RescorlaWagner, input::ModelInput)
    V₋₁ = input.previous_state.expected_reward
    Vₜ = V₋₁ + input.parameters.learning_rate * (input.observation.reward - V₋₁)
    return ModelOutput(BernoulliLogit(Vₜ - 0.5), (; expected_reward = Vₜ))
end

#An environment which gives a reward with a fixed probability, whatever the agent does
struct BernoulliRewards <: AbstractEnvironmentModel end

function CognitiveModeling.apply_model(environment::BernoulliRewards, input::EnvironmentInput)
    reward = float(rand(input.rng) < input.parameters.reward_probability)
    return EnvironmentOutput((; reward))
end

observations, actions, cognitive_states, environment_states = simulate(
    RescorlaWagner(),
    BernoulliRewards();
    who_starts = EnvironmentStarts(),
    n_steps = 3,
    cognitive_parameters = (; learning_rate = 0.5),
    environment_parameters = (; reward_probability = 1.0),
)

cognitive_states

# output

3-element Vector{@NamedTuple{expected_reward::Float64}}:
 (expected_reward = 0.75,)
 (expected_reward = 0.875,)
 (expected_reward = 0.9375,)

Extended help

The return type is concrete as long as the types of the outputs don't change between timesteps. If they do, like an observation that is sometimes NoObservation, the vector for that output holds a Union of the types, and the simulation is a little slower.

Nothing is copied when outputs are saved. A model or environment which changes an object in its state in place, instead of returning a new one, must give a save_state function to ModelOutput or EnvironmentOutput, or all the saved states show the final values, with no error. Observations and actions have no such function, so they must be new objects on each timestep.

Short simulations can be compiled with Reactant, if the action distributions work with traced numbers, which those from Distributions.jl don't. Compile a function that takes a Reactant.ReactantRNG() as a positional argument and passes it on as rng, because @jit doesn't trace keyword arguments and the default generator repeats its numbers on every run. Compile times grow quickly with n_steps, so this is for a few hundred timesteps at most.

CognitiveModeling.ModelInput — Type
ModelInput(observation, previous_state, previous_action, parameters, timestep_size=1,
           rng=default_rng())

Everything a model needs to run a single timestep, which apply_model receives.

Each argument is kept in a field of the same name, such as input.observation.

Arguments

  • observation: what the model observes on this timestep, or NoObservation.
  • previous_state: the state of the model after the previous timestep. On the first timestep, this is the output of initialize_state.
  • previous_action: the action from the previous timestep, or NoAction. A single action is in a NamedTuple, as in input.previous_action.action.
  • parameters: the parameters of the model.
  • timestep_size=1: how much time this timestep covers.
  • rng=default_rng(): the random number generator to sample from if anything in the model is random, so that a simulation can be reproduced.

Examples

julia> using CognitiveModeling: ModelInput

julia> observation = (; reward = 1.0);

julia> state = (; expected_reward = 0.5);

julia> parameters = (; learning_rate = 0.1);

julia> ModelInput(observation, state, NoAction(), parameters).timestep_size
1

julia> ModelInput(observation, state, NoAction(), parameters, 0.5).timestep_size
0.5

CognitiveModeling.ModelOutput — Type
ModelOutput(action_distribution, new_state=(;); save_state=identity)

The outputs of a model for a single timestep, which apply_model returns.

Each argument is kept in a field of the same name, such as output.new_state.

Arguments

  • action_distribution: what the action on this timestep is sampled from. It can be anything that works with rand, such as a distribution from Distributions.jl, and is put in a NamedTuple as (; action = action_distribution). Several actions can be given as a NamedTuple, which names them and samples each of them, and a model without actions gives NoAction.
  • new_state=(;): the state of the model after this timestep, which is the previous_state of the next one.
  • save_state=identity: the function which is applied to new_state when a simulation saves it. By default nothing is copied, so a model which changes an object in its state in place must give a function which copies it. Otherwise all the saved states show the final values, with no error. deepcopy works for any state, but gives wrong gradients with ReverseDiff.jl, also with no error. A function which copies only what changes, such as state -> (; values = copy(state.values)), is faster and works with ReverseDiff.jl too. copy itself doesn't work on a NamedTuple.

Examples

julia> using CognitiveModeling: ModelOutput

julia> using Distributions: Bernoulli

julia> ModelOutput(Bernoulli(0.7), (; expected_reward = 0.5)).new_state
(expected_reward = 0.5,)

julia> ModelOutput(Bernoulli(0.7)).new_state
NamedTuple()

julia> keys(ModelOutput(Bernoulli(0.7)).action_distribution)
(:action,)

julia> keys(ModelOutput((; choice = Bernoulli(0.7))).action_distribution)
(:choice,)

julia> output = ModelOutput(Bernoulli(0.7), (; values = [0.5]); save_state = deepcopy);

julia> output.save_state(output.new_state).values === output.new_state.values
false

CognitiveModeling.apply_model — Method
apply_model(model::AbstractCognitiveModel, input::ModelInput)::ModelOutput

Run a single timestep of model. Usually this involves updating cognitive states and returning an object from which the action is sampled.

Implementation

Every model must add a method of this function, which throws an error otherwise. Anything random should be sampled from input.rng, so that a simulation can be reproduced.

Examples

using CognitiveModeling
using CognitiveModeling: ModelInput, ModelOutput
using Distributions: BernoulliLogit

struct RescorlaWagner <: AbstractCognitiveModel end

function CognitiveModeling.apply_model(model::RescorlaWagner, input::ModelInput)

    ## Unpack input ##
    #Reward observed on this timestep
    r = input.observation.reward
    #Expected reward from the previous state
    V₋₁ = input.previous_state.expected_reward
    #Learning rate parameter
    α = input.parameters.learning_rate
    #Inverse temperature parameter
    β = input.parameters.inverse_temperature

    ## Update state ##
    #Update expected reward using the Rescorla-Wagner rule
    Vₜ = V₋₁ + α * (r - V₋₁)

    ## Compute action probabilities ##
    #Softmax function, instantiated as a Bernoulli logit distribution
    Pₜ = BernoulliLogit(β * (Vₜ - 0.5))

    return ModelOutput(Pₜ, (; expected_reward = Vₜ))
end

parameters = (; learning_rate = 0.1, inverse_temperature = 2.0)
input = ModelInput((; reward = 1.0), (; expected_reward = 0.5), NoAction(), parameters)

CognitiveModeling.apply_model(RescorlaWagner(), input).new_state

# output

(expected_reward = 0.55,)

EnvironmentInput(action, previous_state, previous_observation, parameters,
                 timestep_size=1, rng=default_rng())

Everything an environment model needs to run a single timestep.

Each argument is kept in a field of the same name, such as input.action.

Arguments

  • action: the action that the environment responds to, or NoAction if there is none yet. A single action is in a NamedTuple, as in input.action.action.

  • parameters: the parameters of the environment model.
  • timestep_size=1: how much time this timestep covers.
  • rng=default_rng(): the random number generator to sample from if anything in the environment is random, so that a simulation can be reproduced.
