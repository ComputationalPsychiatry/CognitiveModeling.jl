Simulating

CognitiveModeling.simulate! — Method
simulate!(instantiated_model::InstantiatedModel, input; timestep_size=1,
          rng=default_rng())

Run a single timestep of instantiated_model on input, update it, and return the sampled output. What instantiated_model.save_history selects of the state, the input, the output and the output distribution is added to instantiated_model.history, together with the size of the timestep.

The output is in a NamedTuple with the names the model gave it, as in output.choice, as for simulate. The input must be a NamedTuple with every input in the model's attributes, from attribute_names, or an ArgumentError is thrown.

Arguments

  • instantiated_model::InstantiatedModel: the model to update.
  • input::NamedTuple: what the model receives on this timestep, such as (; reward = 1.0) for a cognitive model. An entry that isn't there is NoValue.
  • timestep_size=1: how much time this timestep covers.
  • rng::AbstractRNG=default_rng(): the random number generator to sample from.

Examples

using CognitiveModeling
using Distributions: Bernoulli

struct RescorlaWagner <: AbstractCognitiveModel end

function CognitiveModeling.initialize_state(model::RescorlaWagner, parameters)
    return (; expected_reward = 0.5)
end

function CognitiveModeling.run_timestep(model::RescorlaWagner, context::ModelContext)
    V₋₁ = context.previous_state.expected_reward
    Vₜ = V₋₁ + context.parameters.learning_rate * (context.input.reward - V₋₁)
    return ModelOutput((; choice = Bernoulli(Vₜ)), (; expected_reward = Vₜ))
end

function CognitiveModeling.attribute_names(model::RescorlaWagner)
    return ModelAttributes(; parameters = :learning_rate, states = :expected_reward, inputs = :reward, outputs = :choice)
end

agent = InstantiatedModel(RescorlaWagner(), (; learning_rate = 0.5); save_history = SaveHistory(SaveEverything()))

simulate!(agent, (; reward = 1.0))
simulate!(agent, (; reward = 1.0))

CognitiveModeling.simulate! — Method
simulate!(agent::InstantiatedModel, environment::InstantiatedModel; <keyword arguments>)

Simulate agent interacting with environment from where they are, update them both, and return the trajectories of this call in the same NamedTuple as simulate, without timestep 0: what agent.save_history selects of the states, observations, actions and action distributions on each timestep, what environment.save_history selects of the environment's under environment, and the sizes of the timesteps. What the two select is also added to agent.history and environment.history, in each model's own names, together with the sizes of the timesteps, unless a selection is empty. A history has timestep 0 from where the model started, when its SaveHistory saves the initial timestep values.

The two models must fit together, as for simulate, directly or through observation_map and action_map. The agent's history holds the observations as its model received them, and the environment's history the actions as its model did.

The simulation stops before n_steps timesteps if stopping_criterion of either model is met, unless check_stopping_criterion is false. A model where it is met already can't be simulated further, and throws an error until it is reset!.

An instantiated model isn't type stable, as InstantiatedModel describes. Use simulate where that matters, or if most calls are for a single timestep.

Arguments

  • who_starts::Union{AgentStarts, EnvironmentStarts}: who moves first on each timestep.
  • n_steps::Int: the number of timesteps to simulate, which must be at least 1. It is the most timesteps there can be when a model has a stopping_criterion.
  • timestep_sizes=1: how much time each timestep covers. A value that isn't a vector, such as a single number, is the size of every timestep of this call. A vector has one size for each timestep of this call, so its length must be n_steps.
  • rng::AbstractRNG=default_rng(): the random number generator to sample from.
  • observation_map::Union{Nothing, NameMap}=nothing: which observations of the environment the agent receives, and under which names, as for simulate.
  • action_map::Union{Nothing, NameMap}=nothing: which actions of the agent the environment receives, and under which names, as for simulate.
  • check_stopping_criterion::Bool=true: whether stopping_criterion of the two models is checked before each timestep, as for simulate.

CognitiveModeling.simulate — Method
simulate(model, input; <keyword arguments>)

Run a single timestep of model, a cognitive model or an environment model, on input, without the other side of a simulation, and return the sampled output and the new state of the model.

Nothing is kept between calls, so pass the returned state and output on as previous_state and previous_output to run the next timestep. simulate! on a single input does the same for an InstantiatedModel, which keeps them. This is type stable, which an instantiated model isn't, so it is the faster of the two.

The output is in a NamedTuple with the names the model gave it, as in output.choice. The input must be a NamedTuple with every input in the model's attributes, from attribute_names, or an ArgumentError is thrown. Parameters that aren't given take the values in default_parameters, if model provides defaults for them, and the names of the parameters, the state and the previous output are checked as in a full simulation.

Arguments

  • model::AbstractTimestepModel: the model.
  • input::NamedTuple: what the model receives on this timestep, such as (; reward = 1.0) for a cognitive model. An entry that isn't there is NoValue.
  • parameters::NamedTuple: the parameters of model, with its default values for those that aren't given, if it provides any.
  • timestep_size=1: how much time this timestep covers.
  • rng::AbstractRNG=default_rng(): the random number generator to sample from.
  • previous_state=initialize_state(model, ...): the state of model before this timestep, by default its initial state from the full parameters. A state that model changes in place will be changed.
  • previous_output=output_before_first_timestep(model): the output before this timestep. By default every output is BeforeFirstTimestep.
  • check_parameter_domains::Bool=true: whether the parameters are checked against their domains in parameter_domains, as for a whole simulation.

CognitiveModeling.simulate — Method
simulate(cognitive_model, environment; <keyword arguments>)

Simulate cognitive_model interacting with environment, and return the trajectories that were saved, which are what changed over the timesteps, in a NamedTuple: states, observations, actions and action_distributions of the cognitive model, environment with the states, observations, actions and observation_distributions of the environment, and timestep_sizes. Each is a vector with one element for timestep 0, before the first timestep, and one for each timestep after it.

Each element is what happened on that timestep, and the states are those after it. The observations are those the cognitive model received, and the actions those it gave, and under environment the observations are those the environment gave and the actions those it received, which differ from the cognitive model's when a NameMap selects or renames them. The action distributions are what the cognitive model gave its actions to be sampled from, and the observation distributions what the environment gave its observations to be sampled from. The element for timestep 0 has the previous observation and action, which are BeforeFirstTimestep unless others are given, BeforeFirstTimestep() for every distribution, and the states before the first timestep. Since Julia counts from 1, element t + 1 is timestep t.

cognitive_save_history and environment_save_history select what is kept of each element of each model, which is nothing by default: give SaveHistory(SaveEverything()) to keep everything, and SaveHistory(SaveEverything(); save_initial_timestep_values = false) to leave out timestep 0, so that element t is timestep t. The vectors of both models have the same length, which cognitive_save_history decides. The sizes of the timesteps are returned as they were given: a single size as it is, and a vector of sizes with the sizes of the timesteps that ran, after BeforeFirstTimestep() for timestep 0 when it is there.

Parameters that aren't given take the values in default_parameters, if cognitive_model or environment provides defaults for them. The names of the parameters, the states, the previous action and the previous observation must be those in attribute_names, and the outputs of each model must be the inputs of the other, or an ArgumentError is thrown before the first timestep. When the two name things differently, or one gives something that isn't in the other's attributes, observation_map and action_map say which outputs of one the other receives, and under which names.

The simulation stops before n_steps timesteps if stopping_criterion of either model is met, unless check_stopping_criterion is false, and everything returned then has the timesteps that ran.

Arguments

  • cognitive_model::AbstractTimestepModel: the cognitive model, usually an AbstractCognitiveModel.
  • environment::AbstractTimestepModel: the environment model, usually an AbstractEnvironmentModel. A cognitive model can serve as the environment of another when its outputs are the inputs in the other's attributes, and vice versa.
  • who_starts::Union{AgentStarts, EnvironmentStarts}: who moves first on each timestep. It has no default, because a wrong choice shifts the model by a timestep without any error.
  • n_steps::Int: the number of timesteps to simulate, which must be at least 1. It is the most timesteps there can be when a model has a stopping_criterion.
  • timestep_sizes=1: how much time each timestep covers, which both cognitive_model and environment receive. A value that isn't a vector, such as a single number, is the size of every timestep. A vector has one size for each timestep, so its length must be n_steps.
  • cognitive_parameters::NamedTuple: the parameters of cognitive_model, with its default values for those that aren't given, if it provides any.
  • environment_parameters::NamedTuple: the parameters of environment, with its default values for those that aren't given, if it provides any.
  • rng::AbstractRNG=default_rng(): the random number generator to sample actions and observations from, which cognitive_model and environment also receive in their contexts.
  • cognitive_save_history::SaveHistory=SaveHistory(): which states, inputs, outputs and output distributions of cognitive_model are saved, by name, and whether timestep 0 is. Nothing is saved by default, and SaveHistory(SaveEverything()) saves everything. See SaveHistory.
  • environment_save_history::SaveHistory=SaveHistory(): the same for environment, whose inputs are the actions it receives and whose outputs are the observations it gives. Whether timestep 0 is saved follows cognitive_save_history, so that the vectors of both models have the same length.
  • observation_map::Union{Nothing, NameMap}=nothing: which observations of environment are passed on to cognitive_model, and under which names, as a NameMap from the names environment gives to exactly those in the attributes of cognitive_model. Without one, the two must have the same observations in their attributes, which cognitive_model receives under the same names.
  • action_map::Union{Nothing, NameMap}=nothing: which actions of cognitive_model are passed on to environment, and under which names, as a NameMap from the names cognitive_model gives to exactly those in the attributes of environment. Without one, the two must have the same actions in their attributes, which environment receives under the same names.
  • check_stopping_criterion::Bool=true: whether stopping_criterion of the two models is checked before each timestep. With false, all of n_steps timesteps run.
  • check_parameter_domains::Bool=true: whether the parameters of the two models are checked against their domains in parameter_domains before the simulation, where a value outside its domain throws a ParameterDomainError.
  • previous_cognitive_state=initialize_state(cognitive_model, ...): the state of cognitive_model before the first timestep, by default its initial state from the full parameters. A state that cognitive_model changes in place will be changed.
  • previous_action=output_before_first_timestep(cognitive_model): the action before the first timestep. By default every action is BeforeFirstTimestep, with the names from attribute_names.
  • previous_environment_state=initialize_state(environment, ...): the state of environment before the first timestep, by default its initial state from the full parameters.
  • previous_observation=output_before_first_timestep(environment): the observation before the first timestep. By default every observation is BeforeFirstTimestep(), with the names from attribute_names of environment.

See also simulate!, which continues from where the last simulation left off.

Extended help

The return type is concrete as long as the types of the outputs don't change between timesteps. If they do, like an observation with an entry that is sometimes NoValue, the vector for that output holds a Union of the types. The same goes for timestep 0 when it has other types than the timesteps after it, which the observations and actions usually do, since they are BeforeFirstTimestep() there.

Nothing is copied when outputs are saved. A model or environment which changes an object in its state in place, instead of returning a new one, must add a method of prepare_state_for_saving, or all the saved states show the final values, with no error. Observations and actions have no such function, so they must be new objects on each timestep.

Instantiated models and name maps

CognitiveModeling.InstantiatedModel — Type
InstantiatedModel(model, parameters; save_history=SaveHistory(),
                  check_parameter_domains=true)
InstantiatedModel(model, parameters, state, previous_output;
                  save_history=SaveHistory(), check_parameter_domains=true)

A cognitive model or an environment model with its parameters, current state and previous output, which simulate! can update iteratively.

Each argument is kept in a field of the same name, such as agent.state. Parameters that aren't given take the values in default_parameters, if the model provides defaults for them. The state defaults to the output of initialize_state with the full parameters, and the previous output to every output being BeforeFirstTimestep. The previous output and the state must be NamedTuples, and the names of the parameters, of the previous output and of the state must be those in the model's attributes, from attribute_names, or an error is thrown.

agent.history holds a ModelHistory with where the model started, which is timestep 0, and everything that happens to it, as selected by save_history, a SaveHistory. By default nothing is selected and the vectors in agent.history stay empty, and SaveHistory(SaveEverything()) saves everything. States, inputs and outputs can only be selected by name among those in the model's attributes, since the history starts from those names. agent.n_timesteps counts the timesteps the model has simulated, whatever is saved. The parameters are checked against their domains in parameter_domains, where a value outside its domain throws a ParameterDomainError, unless check_parameter_domains is false.

In the REPL, an instantiated model shows the kind and the type of its model, how many timesteps it has simulated, and the values of its parameters and of its state, with only how many there are when there are more than five. Large arrays are shortened. When the model's stopping_criterion is met, it says so, since it must then be reset! before it can be simulated again. On one line, as inside a vector, it shows the type and the kind of its model and how many timesteps it has simulated.

An instantiated model is a convenience, and isn't type stable, by design: its state and its previous output can change type, as an output does from BeforeFirstTimestep() to a Bool, and so can what its history saves, so they are kept untyped. Each call of simulate! on it is therefore dynamically dispatched, and the compiler doesn't know what it returns, whatever is saved. Where that matters, use simulate on the models themselves, one timestep at a time or for a whole simulation.

The same type serves as the agent and as the environment of a simulation, since both are models. See also simulate! and reset!.

CognitiveModeling.NameMap — Type
NameMap(names...)

Which outputs of one side of a simulation the other side receives, and under which names.

Each argument is :given => :received, for an output which has another name in the receiver's attributes, or a single Symbol, for one which keeps its name. Outputs that aren't in the map aren't passed on, and each name can only be there once.

simulate and simulate! take one as observation_map, from the observations the environment model gives to those in the cognitive model's attributes, and one as action_map, from the actions the cognitive model gives to those in the environment model's attributes. A cognitive model and an environment which name things differently, or where one gives something that isn't in the other's attributes, can then be used together, and the map says which outputs the receiver gets: it must give exactly the names in the receiver's attributes, from attribute_names. NameMap() passes nothing on, for a receiver without inputs in its attributes. Without a map, the two must have the same names in their attributes.

CognitiveModeling.reset! — Method
reset!(instantiated_model::InstantiatedModel)

Put instantiated_model back to where a new one starts, and return it.

The state becomes the output of initialize_state with the parameters it has, the previous output has every output as BeforeFirstTimestep again, and n_timesteps is 0. The history is a new one which starts from there, as timestep 0 when the SaveHistory saves the initial timestep values, so a history that was read before the reset, as in history = agent.history, is kept as it was. The model, the parameters and the SaveHistory stay the same.

An instantiated model that was created with a state or a previous output of its own doesn't return to those. Create a new one for that.

An environment with fixed observations

CognitiveModeling.FixedObservationsEnvironment — Type
FixedObservationsEnvironment(observations)

An environment model which gives the observations in observations in order, an entry of each on every timestep.

Arguments

  • observations::NamedTuple: a vector for each observation, with an entry for each timestep, such as (; reward = [1.0, 0.0, 1.0]). The vectors must have the same length. Each entry is given in a Deterministic, so nothing is sampled. An entry that is NoValue is given as it is, for a timestep without that observation.

It takes no actions, so a simulation with a cognitive model that gives actions is given action_map = NameMap(), which passes none of them on. Its attribute_names are the observations as outputs, no inputs, no parameters, and the state n_observations_given, the number of timesteps it has given its observations for. Its stopping_criterion is met when every entry is given, so a simulation stops there by itself, and n_steps is the most timesteps it can take. A timestep after the last entry throws an error.

Examples

using CognitiveModeling

#A Rescorla-Wagner model which chooses when it expects more than half a reward

    return ModelOutput((; choice = Deterministic(Vₜ > 0.5)), (; expected_reward = Vₜ))
end
function CognitiveModeling.attribute_names(model::LearnsRewards)
