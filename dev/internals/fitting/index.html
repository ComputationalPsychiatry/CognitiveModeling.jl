parameters_by_session(values_by_session, session_ids)

Return the groups of the sessions in sessions_info by the values of the columns in group_by, a tuple of names, for the parameter parameter_name of a GroupedHierarchicalSessionParameters: a NamedTuple with the group of every session, group_of_each_session, the number of groups, n_groups, and the name of each group, group_names, as session_name names identifiers. CognitiveModeling.column_entry — Method
column_entry(entry)

Return the name the model uses for an attribute and the specification of its column, as a pair, from one entry of the columns of a kind. An entry is a name, for a column that is named as the model names the attribute, or a pair from the specification of the column to the model's name: :outcome => :reward for a column with another name, (:choicecol, :rtcol) => :ssm_action or (; choice = :choicecol, rt = :rtcol) => :ssm_action for a value built from several columns, and (:choicecol, :rtcol) => combine => :ssm_action for what a function gives for their values. Used by column_map.

source
CognitiveModeling.column_map — Method
column_map(columns, cognitive_model, kind)

Return the columns of kind, :observations or :actions, as a NamedTuple from the name the model uses to the specification of the column, from what observation_columns or action_columns of MultipleSessionsInfo was given:

  • a tuple or a vector with an entry for each attribute, see column_entry: a name, for a column that is named as the model names the attribute, or a pair from the specification of the column to the model's name, such as :outcome => :reward;
  • one such pair on its own;
  • a single name, which is the column of the attribute of that kind when the model has only one in its attributes, whatever the column is called. It is an error when the model has several, and when the model lists the name as an attribute of the other kind only, since observation_columns and action_columns may then be swapped. When the model lists none, it is a column of that name;
  • how to build a value from several columns, without the model's name: a NamedTuple of names, or a pair of a tuple of names and a function, for the attribute of that kind when the model has only one in its attributes.

A specification is the name of a column, or how to build one from several, see columns_used. Used by MultipleSessionsInfo when it splits a table.

CognitiveModeling.column_table — Method
column_table(table)

Return table as a NamedTuple with one vector for each column. A NamedTuple is returned as it is, and any other table is read with Tables.jl, through the package's extension for it, which loads with Tables.jl, as it does with DataFrames.jl, CSV.jl and the other packages of tables, since they load Tables.jl. Without it, a table that isn't a NamedTuple is an error. Used by MultipleSessionsInfo when it splits a table.

source
CognitiveModeling.columns_used — Method
columns_used(specification)

Return the names of the columns of a table that one specification of an attribute's column uses, as a tuple. A specification is one of:

  • a Symbol, the column itself;
  • a NamedTuple of Symbols, such as (; choice = :choicecol, rt = :rtcol), for a column of NamedTuples with those names built from the columns, one for each row;
  • a Tuple of Symbols, such as (:choicecol, :rtcol), for a column of Tuples;
  • a Pair of a Tuple of Symbols and a function, such as (:choicecol, :rtcol) => (choice, rt) -> [choice, rt], for a column with what the function gives for the values of each row.

Used by MultipleSessionsInfo when it checks a table, and by build_column.

Return whether a session includes its environment, as the include_environment of SessionInfo says: always with true, which needs an environment, never with false, and with nothing only when an observation or an action is MissingValue, the environment's history is saved, or its stopping criterion is checked on every timestep. CognitiveModeling.mark_missing_values — Method
mark_missing_values(columns, missing_values, impute)

Return columns, a NamedTuple with one vector per name, or a single vector, with every value which is equal to one of missing_values, as isequal compares them, replaced by the marker for a missing value: MissingValue when impute is true. When it is false, the marker is UnimputedMissingValue, which every MissingValue() that is in the data already becomes too.

A column gets the type of the marker in its element type when its element type allows one of the values, whether it holds one or not, so that sessions whose columns have the same types keep them, or when it holds a value equal to one of them of another type, such as -1.0 for -1. Any other column is kept as it is, after narrow_column. Anything that isn't a NamedTuple of vectors is returned as it is, for check_data to report. Used by SessionInfo on the observations and the actions, and by build_column.

CognitiveModeling.recorded_values — Method
recorded_values(columns)

Return the recorded values of each action or observation in columns, a NamedTuple with one vector per name, as a NamedTuple of vectors in the order of the timesteps. Fitting scores these against the distributions the model gave on the same timesteps: the actions against the cognitive model's, and the observations against the environment's. Each vector has the element type of its column without MissingValue and the other markers, so that a session without recorded values for a name gets an empty vector of the same type as other sessions, which scores nothing. A name whose column can only hold those markers is left out, which is decided by its type, so that it is the same for every session of a table. Used by SessionInfo, which keeps the results in its fields recorded_actions and recorded_observations.

CognitiveModeling.store_distributions — Method
store_distributions(distributions, recorded_distributions, recorded_on_timestep)

Add the distributions of the outputs that are recorded on one timestep, where recorded_on_timestep says which, to the vectors in distributions, one for each output that is recorded in the session, and return them. A distribution of another type than its vector widens the vector, as for push_value!. Used by fitted sessions, on every timestep.

CognitiveModeling.timestep_sizes_until — Method
timestep_sizes_until(timestep_sizes, n_saved)

Return the vector of the sizes of the timesteps that a session returns, cut to its first n_saved elements, for a session that ended before its data did when a stopping_criterion was met. An empty vector of sizes, for a session that saves nothing, is kept. Used by fitted sessions.

CognitiveModeling.value_passed_on — Method
value_passed_on(values, name, observation_map, filler)

Return the value in values that the environment's output name is received as: under the same name without a map, under the name observation_map gives it, or filler when the map doesn't pass it on. Used by environment_view.

CognitiveModeling.with_empty_environment_entry — Method
with_empty_environment_entry(saved_trajectories)

Return saved_trajectories, what a session without an environment saved, with an environment entry whose vectors hold an empty NamedTuple for each saved timestep, for a session which has an environment but didn't include it, so that every session with an environment returns the same entries, in the same order, since the model's return otherwise has two types. Used by fitted sessions.

source
CognitiveModeling.without_environment — Method
without_environment(session_info)

Return the session with NoEnvironment() as its environment and everything else the same, so that it runs as a session without an environment. Used by fitted sessions whose environment doesn't run, since every observation is in the data.
