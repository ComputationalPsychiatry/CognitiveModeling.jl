Sessions

CognitiveModeling.prepare_session — Method
prepare_session(cognitive_model, observations, actions; who_starts, <keyword arguments>)

Return the SessionInfo of one session, with the checks of the data and the names, the missing values in the data marked, whether the environment runs, and what is scored and returned prepared, as its constructor describes. Used by SessionInfo and MultipleSessionsInfo.

Workflow and postprocessing

CognitiveModeling.with_save_history — Method
with_save_history(info, cognitive_save_history, environment_save_history)

Return a copy of info, a SessionInfo or a MultipleSessionsInfo, whose sessions save what the two save histories select. Used by the methods of get_session_trajectories and predict_session_trajectories which take a model, to read or simulate the sessions again with what is to be saved.

Reading tables with Tables.jl

CognitiveModeling.column_table — Method
column_table(table)

Return table as a NamedTuple with one vector for each column. A NamedTuple is returned as it is, and any other table is read with Tables.jl, through the package's extension for it, which loads with Tables.jl, as it does with DataFrames.jl, CSV.jl and the other packages of tables, since they load Tables.jl. Without it, a table that isn't a NamedTuple is an error. Used by MultipleSessionsInfo when it splits a table.
