CognitiveModeling.build_contrast_columns — Method
build_contrast_columns(sessions_info, name, columns, regression_parameter,
                       parameter_name)

Return the columns of the categorical predictor name, which reads the columns in columns, in the regression of the parameter parameter_name, in a NamedTuple with names, columns and reference_level: for each level other than the reference level, in the order of their first session, the name of its coefficient, made from the name of the predictor and the symbol name of the level, as in diagnosis_clinical, and a vector with 1 for the sessions of that level and 0 for the others. It is an error when there is one level only, and when the reference level isn't one of them. Used by build_regression_design.

CognitiveModeling.collect_values_to_condition_on — Method
collect_values_to_condition_on(columns)

Return the values to condition on of each action or observation in columns, a NamedTuple with one vector per name, as a NamedTuple of vectors in the order of the timesteps. Fitting scores these against the distributions the model gave on the same timesteps: the actions against the cognitive model's, and the observations against the environment's. Each vector has the element type of its column without MissingValue and the other markers, so that a session without values to condition on for a name gets an empty vector of the same type as other sessions, which scores nothing. A name whose column can only hold those markers is left out, which is decided by its type, so that it is the same for every session of a table. Used by SessionInfo, which keeps the results in its fields actions_to_condition_on and observations_to_condition_on.

CognitiveModeling.mark_missing_values — Method
mark_missing_values(columns, missing_values, impute)

Return columns, a NamedTuple with one vector per name, or a single vector, with every value which is equal to one of missing_values, as isequal compares them, replaced by the marker for a missing value: MissingValue when impute is true. When it is false, the marker is UnimputedMissingValue, which every MissingValue() that is in the data already becomes too.

A column gets the type of the marker in its element type when its element type allows one of the values, whether it holds one or not, so that sessions whose columns have the same types keep them, or when it holds a value equal to one of them of another type, such as -1.0 for -1. Any other column is kept as it is, after narrow_element_type. Anything that isn't a NamedTuple of vectors is returned as it is, for check_data_fits to report. Used by SessionInfo on the observations and the actions, and by build_column.

CognitiveModeling.column_map — Method
column_map(columns, cognitive_model, kind)

Return the columns of kind, :observations or :actions, as a NamedTuple from the name the model uses to the specification of the column, from what observation_columns or action_columns of MultipleSessionsInfo was given:

  • a tuple or a vector with an entry for each attribute, see column_entry: a name, for a column that is named as the model names the attribute, or a pair from the specification of the column to the model's name, such as :outcome => :reward;
  • one such pair on its own;
  • a single name, which is the column of the attribute of that kind when the model has only one in its attributes, whatever the column is called. It is an error when the model has several, and when the model's attributes have the name as one of the other kind only, since observation_columns and action_columns may then be swapped. When its attributes have none of that kind, it is a column of that name;
  • how to build a value from several columns, without the model's name: a NamedTuple of names, or a pair of a tuple of names and a function, for the attribute of that kind when the model has only one in its attributes.

A specification is the name of a column, or how to build one from several, see columns_used. Used by MultipleSessionsInfo when it splits a table.
