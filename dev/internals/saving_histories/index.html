Selecting what is saved

CognitiveModeling.as_selection — Method
as_selection(names)

Return names as a selection, which is how a SaveHistory keeps it: a Tuple of Symbols, made from a single Symbol or a Vector of them too, or SaveEverything as it is. Used by the constructor of SaveHistory.

source
CognitiveModeling.check_savehistory_selection_names — Method
check_savehistory_selection_names(save_history, model)

Throw an informative error if save_history selects a state, an input, an output or an output distribution by name that attribute_names of model, a cognitive model or an environment model, doesn't list, since a history starts from those names, and prepare_state_for_saving returns a state with them. Used by InstantiatedModel, simulate and SessionInfo, before anything is saved.

source
CognitiveModeling.check_selection_names — Method
check_selection_names(selection, names, kind, model)

Throw an informative error if selection has a name that isn't among names, those that model lists for kind, which is "states", "inputs", "outputs" or "output distributions", the last being named like the outputs. SaveEverything can always be selected. Used by check_savehistory_selection_names for each kind.

source
CognitiveModeling.each_timestep_size — Method
each_timestep_size(timestep_sizes, n_steps)

Return the size of each of n_steps timesteps as a vector, for a history. A vector of sizes is returned as it is, and anything else is repeated for every timestep. Used by simulate!, for the sizes it adds to the histories, and by saved_timestep_sizes.

source
CognitiveModeling.returned_timestep_sizes — Method
returned_timestep_sizes(timestep_sizes, n_timesteps, save_initial_values::Val)

Return the sizes of the n_timesteps timesteps that ran, as a simulation returns them. A vector of sizes is cut to those timesteps, since a model can stop a simulation early, and starts with BeforeFirstTimestep for timestep 0 when save_initial_values is Val(true), so that it has an element for each element of what is saved. Anything else is returned as it is, since it is the size of every timestep. Used by simulate, simulate! and saved_timestep_sizes.

source
CognitiveModeling.save_state — Method
save_state(model, state, selection::Val)

Return what is saved of state: what selection selects of the output of prepare_state_for_saving. When nothing is selected, the state isn't prepared at all, so that no copy is made of a state which isn't saved. Used wherever a state is saved, by simulations, instantiated models and fitted sessions.

source
CognitiveModeling.saved_timestep_sizes — Method
saved_timestep_sizes(timestep_sizes, n_steps, save_history)

Return the sizes of n_steps timesteps as they are returned with a history: one size for each timestep when save_history saves anything, after BeforeFirstTimestep for timestep 0 when it saves the initial values, and an empty vector when it saves nothing. Used by SessionInfo, for the sizes a fitted session returns.

source
CognitiveModeling.saves_initial_values — Method
saves_initial_values(save_history)

Return whether save_history saves the values from before the first timestep, as timestep 0. Used by simulate, InstantiatedModel, saved_timestep_sizes and fitted sessions, to decide whether timestep 0 is saved.

source
CognitiveModeling.saves_nothing — Method
saves_nothing(save_history)

Return whether save_history selects nothing of any kind. Whether it saves the initial values doesn't matter, since there is nothing to save of them. Used by simulate!, InstantiatedModel and fitted sessions, which save nothing at all then.

source
CognitiveModeling.select_names — Method
select_names(x, selection::Val)

Return what a SaveHistory selects of x: x itself for SaveEverything, an empty NamedTuple for no names, and the named entries of a NamedTuple for a tuple of names. Used wherever something is saved, by simulations, instantiated models and fitted sessions.

source

state_selection(save_history)

output_distribution_selection(save_history)

Return the selection of one kind in a SaveHistory as a Val. Used wherever something is saved, by simulations, instantiated models and fitted sessions.

Storing what is saved

CognitiveModeling.initialize_storage — Method
initialize_storage(first_value, n_steps)
initialize_storage(initial_value, first_value, n_steps)

Create the vector for saving one kind of value over n_steps timesteps, using the value of the first timestep to set its type. With initial_value, what is saved from before the first timestep, the vector starts with it, as timestep 0, and its type holds both. Used by simulations and by fitted sessions.

source
CognitiveModeling.push_value! — Method
push_value!(storage, value)

Add value at the end of storage, and return the vector. As for store_value!, a value that doesn't fit the type of storage moves the values so far to a wider vector, which is returned instead. Starting from Vector{Union{}}() lets the first value set the type. Used by fitted sessions.

source
CognitiveModeling.store_value! — Method
store_value!(storage, value, t)

Save value as element t of storage, and return the vector.

If the value doesn't fit the type of storage, the values so far are moved to a wider vector which can hold both types, and that vector is returned instead. Used by simulations and by fitted sessions.
