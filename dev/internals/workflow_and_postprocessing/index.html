Sessions with other data

CognitiveModeling.cut_after_last_timestep_with_data — Method
cut_after_last_timestep_with_data(observations, actions, timestep_sizes)

Return observations and actions, the columns of the data of a session, and timestep_sizes, the sizes of its timesteps, without the timesteps after the last one with data, from last_timestep_with_data, in a NamedTuple. Data without any value is returned as it is, with every timestep. Used by the methods of condition_sessions.

source
CognitiveModeling.cut_timestep_sizes — Method
cut_timestep_sizes(timestep_sizes, n_timesteps)

Return the sizes of the first n_timesteps timesteps: those of a vector with a size for each timestep, and a single size for every timestep as it is. Used by cut_after_last_timestep_with_data.

source
CognitiveModeling.session_settings — Method
session_settings(session_info)

Return the settings that session_info, a SessionInfo, was prepared with, as the keyword arguments of SessionInfo that take them: who starts, the environment and the maps, whether the environment is included, the sizes of the timesteps, the SaveTrajectories, the checks, and the observation and the action before the first timestep. Used by with_data and condition_sessions.

source
CognitiveModeling.with_common_element_types — Method
with_common_element_types(columns_of_sessions)

Return the NamedTuples of columns in columns_of_sessions, the observations or the actions of each of several sessions, with the column of each name given the same element type in every session: the types of its entries in all of them. Used by the methods of condition_sessions, so that the sessions have one type, as MultipleSessionsInfo needs.

source
CognitiveModeling.with_data — Method
with_data(session_info, observations, actions;
          timestep_sizes=session_info.timestep_sizes, missing_observation_values=(),
          missing_action_values=())

Return a copy of session_info, a SessionInfo, with observations and actions as its data, prepared again with its settings, so that what is scored and whether the environment runs follow from the new data. The copy has the sizes of the timesteps of session_info, unless others are given, as for data with other timesteps. No value in the data is replaced, unless values that stand for a missing one are given. Used by decondition_sessions and the methods of condition_sessions.

Sessions that save other trajectories

CognitiveModeling.with_save_trajectories — Method
with_save_trajectories(info, save_cognitive_trajectories, save_environment_trajectories)

Return a copy of info, a SessionInfo or a MultipleSessionsInfo, whose sessions save what the two SaveTrajectories select. Used by the methods of get_session_trajectories and predict_session_trajectories which take a model, to read or simulate the sessions again with what is to be saved.
