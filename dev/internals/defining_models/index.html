Types

CognitiveModeling.AbstractAttributeKind — Type
AbstractAttributeKind

Supertype of the kinds of attributes of a model: ParameterKind for its parameters, StateKind for its states, and the subtypes of AbstractObservableAttributeKind, ObservationKind for the observations and ActionKind for the actions. Used to say which kind of attribute something is.

source
CognitiveModeling.AbstractObservableAttributeKind — Type
AbstractObservableAttributeKind

Supertype of the kinds of attributes that the data of a session has: ObservationKind for the observations, which are the inputs in the attributes of its cognitive model, and ActionKind for the actions, which are its outputs. Used when a table is split into sessions and when the data of a session is named, to say which of the two a column or a vector of data is.

source
CognitiveModeling.AbstractTimestepModel — Type
AbstractTimestepModel

Supertype for timestep models: cognitive models and environment models, which every function that a model implements or is used with takes. A model is a subtype of AbstractCognitiveModel or of AbstractEnvironmentModel, and generally not of this type itself.

The two kinds work the same way, one timestep at a time: on each timestep a model receives an input and gives an output, in a ModelContext and a ModelOutput. In a simulation or a fitted session, the outputs of the cognitive model are its actions, which are the inputs of the environment model, and the outputs of the environment model are the observations, which are the inputs of the cognitive model. A cognitive model can therefore also serve as the environment of another.

CognitiveModeling.check_unique_attribute_names — Method
check_unique_attribute_names(attributes)

Throw an ArgumentError if a name in attributes, a ModelAttributes, is used for more than one attribute, within a kind or across the kinds, and return nothing otherwise. Whether the names are unique is decided by unique_names, and the message is only made when they aren't. Used by the constructor of ModelAttributes.

check_each_parameter_in_domain(model, parameters, domains)

Check the value in parameters of each parameter with a domain in domains, with check_values_in_domains. parameters must have every parameter with a domain, which it has when its names are those in the model's attributes. Used by check_parameters_in_domains.

source
CognitiveModeling.check_parameters_in_domains — Method
check_parameters_in_domains(model, parameters)

Throw a ParameterDomainError if a parameter in parameters is outside its domain in parameter_domains of model: of another type than the domain's, or below its lower bound or above its upper bound. Real numbers and values that aren't numbers are checked, and so is every element of an array. A number that isn't a real number is left alone. It is an ArgumentError when the domains aren't ParameterDomains under the names of parameters in the model's attributes. Used by simulate, InstantiatedModel and fitted sessions, before anything runs, unless they are given check_parameter_domains = false.

source
CognitiveModeling.check_value_in_domain — Method
check_value_in_domain(model, name, value, domain)

Throw a ParameterDomainError if value, the value of the parameter name of model, is outside domain, a ParameterDomain: a real number that the domain's type doesn't take, as takes_value decides, or that is below the lower bound or above the upper bound, which a NaN always is, and which is_beyond_bounds decides for a number that isn't one of Julia's own, or a value that isn't a number and isn't of the domain's type. Every element of an array is checked as a value of its own. A number that isn't a real number, and an array of them, is left alone. Used by check_values_in_domains.

source
CognitiveModeling.check_values_in_domains — Method
check_values_in_domains(model, names, values, domains)

Check each of values, a tuple with the values of the parameters names, against the domain at the same place in domains, a tuple of ParameterDomains, with check_value_in_domain, one after the other. Used by check_each_parameter_in_domain.

source
CognitiveModeling.is_beyond_bounds — Method
is_beyond_bounds(value, domain)

Return whether value, a real number which didn't compare as within the bounds of domain, a ParameterDomain, is beyond them. One of Julia's own number types always is. A number of another type, such as one of automatic differentiation, is when it is NaN, or when it is at or beyond the nearest floating-point number below the lower bound or above the upper bound. Used by check_value_in_domain.

source
CognitiveModeling.takes_value — Method
takes_value(type, value)

Return whether a ParameterDomain with type takes the real number value: when it is of the type, when the type is a type of whole numbers and it is a whole number in another number type, such as 3.0, and when the type is Bool and it is 0 or 1. Used by check_value_in_domain.

source
CognitiveModeling.throw_not_of_type — Method
throw_not_of_type(model, name, value, domain)
throw_outside_bounds(model, name, value, domain)

Throw the ParameterDomainError for the parameter name of model, whose value isn't of the type of domain, or is outside its bounds. Used by check_value_in_domain.

Return domain, a ParameterDomain, as the display of a model writes it after the name of its parameter: an interval for a continuous parameter, such as [0, 1] or [0, ∞), the whole numbers of a discrete one, such as {1, 2, …} or {0, 1, …, 5}, and the type of a parameter that isn't a number, such as AbstractString. Used by print_parameter_lines.

CognitiveModeling.print_attribute_names — Method
print_attribute_names(io, attributes; shorten=false, domains=(;), defaults=(;))

Print a line for each kind of attribute in attributes, a ModelAttributes, with none if it has no names of that kind. With shorten, a kind with more names than shows_every_name allows shows only how many there are. When a parameter has a ParameterDomain in domains or a default value in defaults, the parameters are listed one on a line instead, as print_parameter_lines writes them.

The show methods of a ModelAttributes, of a cognitive model and of an environment model each print a header of their own, and then these lines. Only those of the models shorten them and give the domains and the default values, since a ModelAttributes is where the full lists are read.

source
CognitiveModeling.print_current_values — Method
print_current_values(io, label, current_values, field_name)

Print a line with label and current_values, the fields of a model or the parameters or the state of an InstantiatedModel, in a NamedTuple: each name with its value, none when it is empty, and only how many there are, with where to read them, when shows_every_name doesn't allow listing them all. Values are printed compactly, and large arrays are shortened in the REPL. Used by the show methods of a model and of an InstantiatedModel.

source
CognitiveModeling.print_parameter_lines — Method
print_parameter_lines(io, names, domains, defaults; shorten=false)

Print the parameters names one on a line, each with its domain in domains after its name, as describe_domain writes it, and then its default value in defaults, as in inverse_temperature ∈ [0, ∞) (default 2.0). A parameter without either has its name alone. With shorten, only as many are listed as n_parameter_lines allows, and the last line says how many more there are. Used by print_attribute_names.

source
CognitiveModeling.shows_every_name — Method
shows_every_name(io, names)

Return whether a display on io lists every one of names: always when io isn't limited, as when printing to a file, and otherwise when there are at most five. Used by the show methods of a model and of an InstantiatedModel, which give how many there are instead.
