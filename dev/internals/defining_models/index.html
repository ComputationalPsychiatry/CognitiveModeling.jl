Types

CognitiveModeling.AbstractTimestepModel — Type
AbstractTimestepModel

Supertype for timestep models: cognitive models and environment models, which every function that a model implements or is used with takes. A model is a subtype of AbstractCognitiveModel or of AbstractEnvironmentModel, and generally not of this type itself.

The two kinds work the same way, one timestep at a time: on each timestep a model receives an input and gives an output, in a ModelContext and a ModelOutput. In a simulation or a fitted session, the outputs of the cognitive model are its actions, which are the inputs of the environment model, and the outputs of the environment model are the observations, which are the inputs of the cognitive model. A cognitive model can therefore also serve as the environment of another.

CognitiveModeling.check_unique_attribute_names — Method
check_unique_attribute_names(attributes)

Throw an ArgumentError if a name in attributes, a ModelAttributes, is used for more than one attribute, within a kind or across the kinds, and return nothing otherwise. Whether the names are unique is decided by unique_names, and the message is only made when they aren't. Used by the constructor of ModelAttributes.

CognitiveModeling.check_each_parameter_domain — Method
check_each_parameter_domain(model, parameters, domains)

Check the value in parameters of each parameter with a domain in domains, one at a time, with check_value_in_domain. The names are read from the types, so that the values are checked without any search for them when the model runs. Used by check_parameter_domains.

source
CognitiveModeling.check_parameter_domains — Method
check_parameter_domains(model, parameters)

Throw an InvalidParametersError if a parameter in parameters is outside its domain in parameter_domains of model: below lower, above upper, or not a whole number when it is discrete. Real numbers and arrays of them are checked, and anything else is left alone, such as the traced numbers of Reactant.jl, whose values can't be compared while a simulation is compiled. It is an ArgumentError when the domains name a parameter that isn't in the model's attributes, or have a field other than lower, upper and discrete. Used by simulate, InstantiatedModel and fitted sessions, before anything runs.

source
CognitiveModeling.check_value_in_domain — Method
check_value_in_domain(model, name, value, domain)

Throw an InvalidParametersError if value, the value of the parameter name of model, is outside domain, a NamedTuple with any of lower, upper and discrete. Every element of an array of real numbers is checked, and a value that is neither is left alone. Used by check_each_parameter_domain.

output_before_first_timestep(model)
input_before_first_timestep(model)

Return the output and the input from before the first timestep: a NamedTuple with the output or the input names in the attributes of model, a cognitive model or an environment model, from attribute_names, or those that attributes, a ModelAttributes, has, each BeforeFirstTimestep. CognitiveModeling.print_attribute_names — Method
print_attribute_names(io, attributes; shorten=false)

Print a line for each kind of attribute in attributes, a ModelAttributes, with none if it has no names of that kind. With shorten, a kind with more names than shows_every_name allows shows only how many there are.

The show methods of a ModelAttributes, of a cognitive model and of an environment model each print a header of their own, and then these lines. Only those of the models shorten them, since a ModelAttributes is where the full lists are read.

source
CognitiveModeling.print_current_values — Method
print_current_values(io, label, current_values, field_name)

Print a line with label and current_values, the fields of a model or the parameters or the state of an InstantiatedModel, in a NamedTuple: each name with its value, none when it is empty, and only how many there are, with where to read them, when shows_every_name doesn't allow listing them all. Values are printed compactly, and large arrays are shortened in the REPL. Used by the show methods of a model and of an InstantiatedModel.

source
CognitiveModeling.shows_every_name — Method
shows_every_name(io, names)

Return whether a display on io lists every one of names: always when io isn't limited, as when printing to a file, and otherwise when there are at most five. Used by the show methods of a model and of an InstantiatedModel, which give how many there are instead.
