any_column_can_hold_simulated_value(columns)

Return whether any of columns, a tuple of vectors, has an element type which SimulatedMissingValue belongs to. Used by can_hold_simulated_value.

CognitiveModeling.can_hold_simulated_value — Method
can_hold_simulated_value(observations, actions)

Return whether a column of observations or actions, the data of a session, can hold SimulatedMissingValue, which the element types of the columns say. Used by simulates_values and marker_of_unmapped_outputs.

CognitiveModeling.check_environment_parameters — Method
check_environment_parameters(session_info, environment_parameters)
check_environment_parameters(sessions_info, environment_parameters)

Throw an informative error if environment parameters are given for a session, or for sessions, without an environment model, which is decided by the types. Used by the models of several sessions.

source
CognitiveModeling.data_continues_after — Method
data_continues_after(session_info, t)

Return whether the data of a session has a value on a timestep after t, the last one that ran, so that a stopping_criterion met there ends the session while its data continues, which the parameters then can't give: an action, or an observation when the session includes its environment and scores the observations. The observations of a session without its environment are what the cognitive model receives, which can continue after the model stops. Used by fitted sessions when a stopping criterion is met.

source
CognitiveModeling.has_environment — Method
has_environment(session_info)
has_environment(sessions_info)

Return whether a SessionInfo has an environment model, or every session of a MultipleSessionsInfo has, which is decided by the type. A session can have an environment which doesn't run, see SessionInfo. Used by check_environment_parameters.

source
CognitiveModeling.last_timestep_with_data — Method
last_timestep_with_data(columns)

Return the last timestep on which any column in columns, a NamedTuple of vectors, has a value that isn't ImputedMissingValue or SimulatedMissingValue, and 0 when none has. Any other marker counts as data, since it says that the timestep happened. Used by SessionInfo, which keeps it for data_continues_after.

source
CognitiveModeling.session_parameters_valid — Method
session_parameters_valid(parameters_valid, criterion_allows_data)

Return whether the parameters of a session stayed valid, from parameters_valid, as the models gave it on the last timestep that ran, and criterion_allows_data, which is false when a stopping_criterion ended the session while its data continues, as a Bool, also for models that can't set parameters_valid, since the criterion can end the session. Used by fitted sessions, so that what a session returns has one type.

source
CognitiveModeling.sessions_save_anything — Method
sessions_save_anything(sessions_info)

Return whether the SaveTrajectories of either model of any session in sessions_info selects anything. Used by the full models of the inference backends, to warn when the sessions save trajectories that nothing in the model uses.

source
CognitiveModeling.simulates_values — Method
simulates_values(session_info)
simulates_values(sessions_info)

Return whether the data of a SessionInfo, or of every session of a MultipleSessionsInfo, can hold SimulatedMissingValue, as that of a session from decondition_sessions does, so that its model simulates the values instead of being fitted to them. Used by the inference backends' models of several sessions, which name the variables of such sessions apart from those of fitted ones, and by condition_sessions.

source
CognitiveModeling.submodel_state_names — Method
submodel_state_names(::NoEnvironment)

Return (;), since a session without an environment has no state of a submodel of one. Used by submodel_states_of.

build_named_entry(::Val{name}, value)

Return (; name = value). A NamedTuple which holds a value that can have two types is built with merge of these. Used by select_timestep_values_to_save and by the timesteps of fitted sessions.

CognitiveModeling.has_missing_value — Method
has_missing_value(data)

Return whether any entry of data, the NamedTuple of the actions or the observations of one timestep, is ImputedMissingValue or SimulatedMissingValue. Used by the timesteps of fitted sessions, to skip imputing when nothing is missing.

source
CognitiveModeling.prepend_value — Method
prepend_value(value, values)

Return the tuple values with value in front. Used by read_row_values.

source
CognitiveModeling.read_row_values — Method
read_row_values(columns, t)

Return the values at timestep t of columns, a tuple of vectors, as a tuple. Each value is put in front of the values of the remaining columns by prepend_value, a call of its own, so that a value which can have two types gives one of two tuples with concrete elements, since the compiler splits a call over the types of its arguments. Used by select_row.

source
CognitiveModeling.select_row — Method
select_row(columns, t)

Return the NamedTuple of the values at timestep t of columns, a NamedTuple of vectors with one entry for each timestep. The values are read as a tuple with read_row_values, so that a column which holds two types, such as an action that is ImputedMissingValue on some timesteps, gives one of two NamedTuples with concrete fields rather than one without a definite type. Used by the timesteps of fitted sessions, by the models of several sessions, which read the parameters of one session with it, and by a FixedObservationsEnvironment, which reads the observations of a timestep.

Values to condition on

CognitiveModeling.action_names_to_condition_on — Method
action_names_to_condition_on(session_info)
observation_names_to_condition_on(session_info)

Return the names of the actions, or of the observations, that have values to condition on in the data of a session, which are scored against the distributions the cognitive model, or the environment model, gave for them, in a Val. A session without an environment scores no observations, so it has no such names. Used by fitted sessions, to select the distributions they score.

source
CognitiveModeling.find_outputs_to_condition_on — Method
find_outputs_to_condition_on(data_output, output_distribution, model)

Return whether each output of model on one timestep has a value to condition on in the data, as a NamedTuple of Bools with the names of data_output: the actions of a cognitive model, or the observations an environment model gives. Such a value is scored against the distribution the model gave for it in output_distribution, so it is an error when the model gave nothing for it, NoValue. Used by the timesteps of fitted sessions.

source
CognitiveModeling.initialize_output_distributions_for_conditioning — Method
initialize_output_distributions_for_conditioning(distributions_for_conditioning)

Return an empty vector for the distributions of each output that has values to condition on in a session, typed by the distribution the model gave on the first timestep, so that the vectors keep one type through the session when every timestep gives the same type. An output the model doesn't give on the first timestep gets a Vector{Union{}}(), which the first distribution kept sets the type of, as for push_value!. Used by fitted sessions, after their first timestep.

source
CognitiveModeling.is_value_to_condition_on — Method
is_value_to_condition_on(value)

Return whether a single action or observation in the data is a value to condition on: neither ImputedMissingValue, SimulatedMissingValue nor an AbstractNoValue, such as UnimputedMissingValue or NoValue. Used by collect_values_to_condition_on and find_outputs_to_condition_on.

source
CognitiveModeling.store_output_distributions_for_conditioning — Method
store_output_distributions_for_conditioning(distributions,
                                            distributions_for_conditioning,
                                            outputs_to_condition_on)

Add the distributions of the outputs to condition on at one timestep, which outputs_to_condition_on says, to the vectors in distributions, one for each output that has values to condition on in the session, and return them. A distribution of another type than its vector widens the vector, as for push_value!. Used by fitted sessions, on every timestep.

Saving what a fitted session returns

CognitiveModeling.parameters_valid_in_every_session — Method
parameters_valid_in_every_session(saved_trajectories)

Return whether the parameters stayed valid in every session, from saved_trajectories, a vector with the SessionTrajectories of each fitted session, which have whether its parameters stayed valid, as the models gave it, and false when a stopping criterion ended the session while its data continues. Used by the full model, which runs its downstream model only when they did.

source
CognitiveModeling.select_cognitive_timestep_values_to_save — Method
select_cognitive_timestep_values_to_save(cognitive_model, timestep_values,
                                         save_trajectories)
select_environment_timestep_values_to_save(environment, environment_timestep_values,
                                           save_trajectories)

Return what save_trajectories selects of one model's part of the values of a timestep: the states, observations, actions and action_distributions of the cognitive model, or the states, observations, actions and observation_distributions of the environment, from the values of the environment alone. The observation and the action can have one of two types, so they go in through build_named_entry. Used by select_timestep_values_to_save.

source
CognitiveModeling.select_initial_timestep_values_to_save — Method
select_initial_timestep_values_to_save(save_initial_timestep_values::Val, session_info,
                                       previous)

Return what a session saves from before the first timestep, as timestep 0, when save_initial_timestep_values is Val(true), and nothing otherwise. previous has the values that the first timestep starts from, arranged as those of a timestep. The distributions of timestep 0 are BeforeFirstTimestep for every output of each model, since none was given yet. Used by fitted sessions, before their first timestep runs.

source
CognitiveModeling.select_timestep_values_to_save — Method
select_timestep_values_to_save(session_info, timestep_values)

Return what a session saves of the values of one timestep, or of where it starts, as the SaveTrajectories of session_info select it, arranged as the session returns it: the cognitive model's states, observations, actions and action_distributions, and with an environment its states, observations, actions and observation_distributions under environment, as map_saved arranges them. timestep_values has the cognitive model's state, observation, action and action_distribution, and under environment the environment's state, observation, action and observation_distribution, each in its own names. Used by fitted sessions, on every timestep.

source
CognitiveModeling.timestep_sizes_until — Method
timestep_sizes_until(timestep_sizes, n_saved)

Return the vector of the sizes of the timesteps that a session returns, cut to its first n_saved elements, for a session that ended before its data did when a stopping_criterion was met. An empty vector of sizes, for a session that saves nothing, is kept. Used by fitted sessions.

source
CognitiveModeling.with_empty_environment_trajectories — Method
with_empty_environment_trajectories(saved_trajectories)

Return saved_trajectories, the SessionTrajectories of a session without an environment, with trajectories of an environment whose vectors hold an empty NamedTuple for each saved timestep, for a session which has an environment but didn't include it, so that every session with an environment returns trajectories of an environment, since the model's return otherwise has two types. Used by fitted sessions.

Masking the timesteps of a fitted session

CognitiveModeling.count_masked_fitted_timestep — Method
count_masked_fitted_timestep(masking, timestep_values)

Return what a masked fitted session carries after a timestep whose values are timestep_values, from masking, what it carried before it. The timestep is kept when the session was running before it and the parameters stayed valid on it. Otherwise the session isn't running after it, the number of timesteps kept stays as it was, and the next timestep starts from the values the timestep started from, which select_values selects. Used by fitted sessions that a compiler like Reactant.jl compiles.

source
CognitiveModeling.log_density_of_masked_ending — Method
log_density_of_masked_ending(masking)

Return what a masked fitted session adds to the log density for how it ended, from masking, what it carried after its last timestep: 0.0 when the parameters stayed valid, and -Inf otherwise, also when a stopping criterion ended the session while its data continues. The session scores every timestep, also those after it ended, since data after the end only exists when the parameters are invalid, and imputed values after it keep their scores, so that each stays a variable with a density. Used by fitted sessions that a compiler like Reactant.jl compiles.

source
CognitiveModeling.masking_fitted_session_after_first_timestep — Method
masking_fitted_session_after_first_timestep(timestep_values, stopped_before_first,
                                            data_continues_before_first)

Return what a masked fitted session carries after its first timestep, whose values are timestep_values, in a NamedTuple: whether it is still running, which it isn't when the stopping criterion was met before it, as stopped_before_first says, or the parameters turned invalid on it, whether the parameters stayed valid, under parameters_valid, which they didn't when the criterion was met before the first timestep while the data continues, as data_continues_before_first says, the number of timesteps kept, under n_timesteps, and the values that the next timestep starts from, under previous. The timesteps after a first timestep that didn't count start from its values, since the values from before it can have other types. Used by fitted sessions that a compiler like Reactant.jl compiles.

source
CognitiveModeling.masking_fitted_session_before_timestep — Method
masking_fitted_session_before_timestep(timestep_values, t)

Return what a fitted session that is masked from timestep t on carries before it, as masking_fitted_session_after_first_timestep arranges it: it is running, with valid parameters and the t - 1 timesteps before kept, the last of which has the values timestep_values. Used by fitted sessions which switch to masking where a flag first must be masked.

source
CognitiveModeling.stop_masked_fitted_session — Method
stop_masked_fitted_session(masking, criterion_met, data_continues::Bool)

Return masking, what a masked fitted session carries, as masking_fitted_session_after_first_timestep arranges it, after the stopping criterion of either model was checked before a timestep, as criterion_met says: the session is no longer running when it was met, and its parameters are invalid when it was met while the session ran and its data continues, as data_continues says. Used by fitted sessions that a compiler like Reactant.jl compiles.

source
CognitiveModeling.values_to_continue_fitted_session_from — Method
values_to_continue_fitted_session_from(timestep_values)

Return the values of a timestep of a fitted session that the next one starts from: everything in timestep_values but what is scored or checked of the timestep itself, its action_distribution, actions_to_condition_on_at_timestep and parameters_valid, and under environment its observation_distribution and observations_to_condition_on_at_timestep. Used by the masking of fitted sessions, which selects them with select_values.
