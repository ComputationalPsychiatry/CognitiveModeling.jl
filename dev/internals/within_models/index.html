CognitiveModeling.check_environment_parameters — Method
check_environment_parameters(session_info, environment_parameters)
check_environment_parameters(sessions_info, environment_parameters)

Throw an informative error if environment parameters are given for a session, or for sessions, without an environment model, which is decided by the types. Used by the models of several sessions.

source
CognitiveModeling.has_environment — Method
has_environment(session_info)
has_environment(sessions_info)

Return whether a SessionInfo has an environment model, or every session of a MultipleSessionsInfo has, which is decided by the type. A session can have an environment which doesn't run, see SessionInfo. Used by check_environment_parameters.

source
CognitiveModeling.last_timestep_with_data — Method
last_timestep_with_data(columns)

Return the last timestep on which any column in columns, a NamedTuple of vectors, has a value that isn't MissingValue, and 0 when none has. Any other marker counts as data, since it says that the timestep happened. Used by first_timestep_to_check_stopping.

source
CognitiveModeling.sessions_save_anything — Method
sessions_save_anything(sessions_info)

Return whether the save history of either model of any session in sessions_info selects anything. Used by the full models of the inference backends, to warn when the sessions save trajectories that nothing in the model uses.

Reading the data of one timestep

CognitiveModeling.build_named_entry — Method
build_named_entry(::Val{name}, value)

Return (; name = value). A NamedTuple which holds a value that can have two types is built with merge of these. Used by select_timestep_values_to_save and by the timesteps of fitted sessions.

source
CognitiveModeling.has_missing_value — Method
has_missing_value(data)

Return whether any entry of data, the NamedTuple of the actions or the observations of one timestep, is MissingValue. Used by the timesteps of fitted sessions, to skip imputing when nothing is missing.

source
CognitiveModeling.prepend_value — Method
prepend_value(value, values)

Return the tuple values with value in front. Used by read_row_values.

source
CognitiveModeling.read_row_values — Method
read_row_values(columns, t)

Return the values at timestep t of columns, a tuple of vectors, as a tuple. Each value is put in front of the values of the remaining columns by prepend_value, a call of its own, so that a value which can have two types gives one of two tuples with concrete elements, since the compiler splits a call over the types of its arguments. Used by select_row.

source
CognitiveModeling.select_row — Method
select_row(columns, t)

Return the NamedTuple of the values at timestep t of columns, a NamedTuple of vectors with one entry for each timestep. The values are read as a tuple with read_row_values, so that a column which holds two types, such as an action that is MissingValue on some timesteps, gives one of two NamedTuples with concrete fields rather than one without a definite type. Used by the timesteps of fitted sessions, and by the models of several sessions, which read the parameters of one session with it.

Values to condition on

CognitiveModeling.action_names_to_condition_on — Method
action_names_to_condition_on(session_info)
observation_names_to_condition_on(session_info)

Return the names of the actions, or of the observations, that have values to condition on in the data of a session, which are scored against the distributions the cognitive model, or the environment model, gave for them, in a Val. A session without an environment scores no observations, so it has no such names. Used by fitted sessions, to select the distributions they score.

source
CognitiveModeling.find_outputs_to_condition_on — Method
find_outputs_to_condition_on(data_output, output_distribution, model)

Return whether each output of model on one timestep has a value to condition on in the data, as a NamedTuple of Bools with the names of data_output: the actions of a cognitive model, or the observations an environment model gives. Such a value is scored against the distribution the model gave for it in output_distribution, so it is an error when the model gave nothing for it, NoValue. Used by the timesteps of fitted sessions.

source
CognitiveModeling.initialize_output_distributions_for_conditioning — Method
initialize_output_distributions_for_conditioning(distributions_for_conditioning)

Return an empty vector for the distributions of each output that has values to condition on in a session, typed by the distribution the model gave on the first timestep, so that the vectors keep one type through the session when every timestep gives the same type. An output the model doesn't give on the first timestep gets a Vector{Union{}}(), which the first distribution kept sets the type of, as for push_value!. Used by fitted sessions, after their first timestep.

source
CognitiveModeling.is_value_to_condition_on — Method
is_value_to_condition_on(value)

Return whether a single action or observation in the data is a value to condition on: neither MissingValue nor an AbstractNoValue, such as UnimputedMissingValue or NoValue. Used by collect_values_to_condition_on and find_outputs_to_condition_on.

source
CognitiveModeling.store_output_distributions_for_conditioning — Method
store_output_distributions_for_conditioning(distributions,
                                            distributions_for_conditioning,
                                            outputs_to_condition_on)

Add the distributions of the outputs to condition on at one timestep, which outputs_to_condition_on says, to the vectors in distributions, one for each output that has values to condition on in the session, and return them. A distribution of another type than its vector widens the vector, as for push_value!. Used by fitted sessions, on every timestep.

Saving what a fitted session returns

CognitiveModeling.select_cognitive_timestep_values_to_save — Method
select_cognitive_timestep_values_to_save(cognitive_model, timestep_values, save_history)
select_environment_timestep_values_to_save(environment, environment_timestep_values,
                                           save_history)

Return what save_history selects of one model's part of the values of a timestep: the states, observations, actions and action_distributions of the cognitive model, or the states, observations, actions and observation_distributions of the environment, from the values of the environment alone. The observation and the action can have one of two types, so they go in through build_named_entry. Used by select_timestep_values_to_save.

source
CognitiveModeling.select_initial_timestep_values_to_save — Method
select_initial_timestep_values_to_save(save_initial_timestep_values::Val, session_info,
                                       previous)

Return what a session saves from before the first timestep, as timestep 0, when save_initial_timestep_values is Val(true), and nothing otherwise. previous has the values that the first timestep starts from, arranged as those of a timestep. The distributions of timestep 0 are BeforeFirstTimestep for every output of each model, since none was given yet. Used by fitted sessions, before their first timestep runs.

source
CognitiveModeling.select_timestep_values_to_save — Method
select_timestep_values_to_save(session_info, timestep_values)

Return what a session saves of the values of one timestep, or of where it starts, as the save histories of session_info select it, arranged as the session returns it: the cognitive model's states, observations, actions and action_distributions, and with an environment its states, observations, actions and observation_distributions under environment, as map_saved arranges them. timestep_values has the cognitive model's state, observation, action and action_distribution, and under environment the environment's state, observation, action and observation_distribution, each in its own names. Used by fitted sessions, on every timestep.

source
CognitiveModeling.timestep_sizes_until — Method
timestep_sizes_until(timestep_sizes, n_saved)

Return the vector of the sizes of the timesteps that a session returns, cut to its first n_saved elements, for a session that ended before its data did when a stopping_criterion was met. An empty vector of sizes, for a session that saves nothing, is kept. Used by fitted sessions.

source
CognitiveModeling.with_empty_environment_entry — Method
with_empty_environment_entry(saved_trajectories)

Return saved_trajectories, what a session without an environment saved, with an environment entry whose vectors hold an empty NamedTuple for each saved timestep, for a session which has an environment but didn't include it, so that every session with an environment returns the same entries, in the same order, since the model's return otherwise has two types. Used by fitted sessions.
