Simulating

CognitiveModeling.check_names_fit — Function
check_names_fit(cognitive_model, environment, observation_map=nothing,
                action_map=nothing)

Throw an informative error if cognitive_model and environment can't be simulated together. Without a map, the outputs of each must be the inputs of the other in attribute_names: the observations the environment gives are the inputs in the cognitive model's attributes, and the actions the cognitive model gives are the inputs in the environment's attributes. With a NameMap for the observations or the actions, the map must take names in the giver's attributes, and give exactly the names in the receiver's attributes. Used by simulate, simulate!, and SessionInfo for a session with an environment.

CognitiveModeling.check_stopping_criterion_not_met — Method
check_stopping_criterion_not_met(model, state, parameters)

Throw an informative error if stopping_criterion of model is already met with state, before the first timestep, since no timestep can then run. Used for each model by simulate_all_timesteps, and by fitted sessions, where there is nothing to check for an environment a session doesn't have.

CognitiveModeling.collect_initial_timestep_values — Method
collect_initial_timestep_values(save_initial_timestep_values::Val,
                                previous_timestep_values, cognitive_model,
                                environment, observation_map, action_map,
                                cognitive_save_history, environment_save_history)

Return what is saved from before the first timestep, as timestep 0, arranged as the saved values of collect_timestep_values, or nothing when save_initial_timestep_values is Val(false).

The observation and the action are the previous ones, as each side receives them, the output distributions are BeforeFirstTimestep for every output, since none was given yet, and the states are the states before the first timestep. They must be saved before the first timestep is simulated, since it can change a state in place. Used by simulate_all_timesteps.

CognitiveModeling.collect_timestep_values — Method
collect_timestep_values(environment_output, cognitive_output, environment_observation,
                        observation, action, environment_action, cognitive_model,
                        environment, cognitive_save_history, environment_save_history)

Collect the values of a timestep in a NamedTuple: the state and the action of the cognitive model, and under environment the state and the observation of the environment, which the next timestep starts from, and under saved what cognitive_save_history and environment_save_history select, as map_saved arranges them.

Each side has the values in its own names: observation is the observation as the cognitive model receives it and environment_observation as the environment gave it, and action is the action as the cognitive model gave it and environment_action as the environment receives it. The two of a pair differ when a NameMap selects or renames them. Used by simulate_timestep.

CognitiveModeling.map_names — Method
map_names(x, name_map)

Return what the receiver gets of the outputs x: all of x without a map, and with a NameMap the outputs it takes, under the names it gives them. Used on each timestep of a simulation, by simulate_timestep, and for timestep 0 by collect_initial_timestep_values.

CognitiveModeling.map_saved — Method
map_saved(f, saved...)

Apply f to each kind of saved value in saved, and return the results arranged in the same way: the cognitive model's states, observations, actions and action_distributions, and under environment the environment's states, observations, actions and observation_distributions, as simulate returns them. What a fitted session without an environment saves has no environment, and is arranged without one. With several, f takes the values of the same kind from each. Used to create, fill and shorten the vectors of the storage of a simulation and of a fitted session.

CognitiveModeling.sample_output — Method
sample_output(rng, output_distribution)

Sample an output from what a model returned, using rand. Each output in a NamedTuple is sampled on its own, so a NamedTuple inside it gives a NamedTuple of samples, and an entry that is NoValue is kept. A number, a string or a symbol is a value and not something to sample from, and throws an ArgumentError which names Deterministic. Used on each timestep of a simulation, by simulate_timestep.

CognitiveModeling.simulate_all_timesteps — Method
simulate_all_timesteps(previous_timestep_values, who_starts, cognitive_model,
                       environment, cognitive_parameters, environment_parameters,
                       cognitive_save_history, environment_save_history,
                       observation_map, action_map, rng, timestep_sizes, n_steps,
                       save_initial_timestep_values::Val, check_stopping_criterion)

Simulate up to n_steps timesteps starting from previous_timestep_values, and return the vectors with what the simulated timesteps saved, followed by the values of the last one. When check_stopping_criterion is true, the simulation stops before n_steps timesteps if stopping_criterion of either model is met, and none can be simulated if it is met already. When save_initial_timestep_values is Val(true), each vector starts with what is saved from before the first timestep, as timestep 0.

previous_timestep_values and the values returned are those of a timestep: the state and the action of the cognitive model, and under environment the state and the observation of the environment, each in its own names. The vectors are arranged as map_saved arranges them, with what cognitive_save_history and environment_save_history select.

simulate! continues from the values of the last timestep instead of from what was saved, because what is saved of a state can be a selection or a copy of it, and because the next simulation can change a state in place. Used by simulate and simulate!.

CognitiveModeling.simulate_remaining_timesteps — Method
simulate_remaining_timesteps(storage, timestep_values, who_starts, cognitive_model,
                             environment, cognitive_parameters, environment_parameters,
                             cognitive_save_history, environment_save_history,
                             observation_map, action_map, rng, timestep_sizes, n_steps,
                             offset, check_stopping_criterion)

Simulate the timesteps after the first, and return the vectors with what the simulated timesteps saved, followed by the values of the last one. When check_stopping_criterion is true, the simulation stops before n_steps timesteps if stopping_criterion of either model is met. offset is 1 when the vectors start with timestep 0, and 0 otherwise, so that timestep t is element t + offset. Used by simulate_all_timesteps.

CognitiveModeling.simulate_timestep — Method
simulate_timestep(model, input, previous_state, previous_output, parameters,
                  timestep_size, rng, save_history)

Simulate a timestep of model on input, without the other side of a simulation, and return the output sampled from what it gave, its new state, and under saved what save_history selects of its states, inputs, outputs and output_distributions, in a NamedTuple. The input must have the names in the attributes of model. simulate and simulate! on a single input both use this.

CognitiveModeling.starting_history — Method
starting_history(model, state, previous_output, save_history)

Return the history that an InstantiatedModel starts with: a ModelHistory with what save_history selects of where it starts, as timestep 0, and BeforeFirstTimestep as the size of the timestep, since none has run yet. When nothing is selected, or save_history doesn't save the initial timestep values, the vectors are empty.

A model hasn't received anything when it starts, so that entry has every input in the model's attributes as BeforeFirstTimestep(), and so has every output distribution. reset! starts from the same history as the constructors.
