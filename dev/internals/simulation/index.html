Simulating

CognitiveModeling.check_names_fit — Function
check_names_fit(cognitive_model, environment, observation_map=nothing,
                action_map=nothing)

Throw an informative error if cognitive_model and environment can't be simulated together. Without a map, the outputs of each must be the inputs of the other in attribute_names: the observations the environment gives are the inputs in the cognitive model's attributes, and the actions the cognitive model gives are the inputs in the environment's attributes. With a NameMap for the observations or the actions, the map must take names in the giver's attributes, and give exactly the names in the receiver's attributes. Used by simulate_session, simulate_session!, and SessionInfo for a session with an environment.

Used by check_names_fit.

CognitiveModeling.check_stopping_criterion_not_met — Method
check_stopping_criterion_not_met(model, state, parameters)

Throw an informative error if stopping_criterion of model is already met with state and parameters, before the first timestep, since no timestep can then run, and return false otherwise. A criterion that must be masked, as masks_bool says, such as a traced Bool of a compiler like Reactant.jl, can't be checked, and is returned instead, for the masking of the simulation or the session. Used for each model by simulate_all_timesteps, and by fitted sessions, where there is nothing to check for an environment a session doesn't have.

CognitiveModeling.collect_initial_timestep_values — Method
collect_initial_timestep_values(save_initial_timestep_values::Val,
                                previous_timestep_values, cognitive_model,
                                environment, observation_map, action_map,
                                save_cognitive_trajectories,
                                save_environment_trajectories)

Return what is saved from before the first timestep, as timestep 0, arranged as the saved values of collect_timestep_values, or nothing when save_initial_timestep_values is Val(false).

The observation and the action are the previous ones, as each side receives them, the output distributions are BeforeFirstTimestep for every output, since none was given yet, and the states are the states before the first timestep. They must be saved before the first timestep is simulated, since it can change a state in place. Used by simulate_all_timesteps.

CognitiveModeling.collect_timestep_values — Method
collect_timestep_values(environment_output, cognitive_output, environment_observation,
                        observation, action, environment_action, cognitive_model,
                        environment, save_cognitive_trajectories,
                        save_environment_trajectories, previous)

Collect the values of a timestep in a NamedTuple: the state and the action of the cognitive model, and under environment the state and the observation of the environment, which the next timestep starts from, whether the parameters of both models are valid, under parameters_valid, the states of both models before and after the timestep, under record, from record_of_timestep, and under saved what save_cognitive_trajectories and save_environment_trajectories select, as map_saved arranges them.

Each side has the values in its own names: observation is the observation as the cognitive model receives it and environment_observation as the environment gave it, and action is the action as the cognitive model gave it and environment_action as the environment receives it. The two of a pair differ when a NameMap selects or renames them. previous holds the values of the timestep before. Used by simulate_timestep_both_models.

CognitiveModeling.map_saved — Method
map_saved(f, saved...)

Apply f to each kind of saved value in saved, and return the results arranged in the same way: the cognitive model's states, observations, actions and action_distributions, and under environment the environment's states, observations, actions and observation_distributions, as simulate_session returns them. What a fitted session without an environment saves has no environment, and is arranged without one. With several, f takes the values of the same kind from each. Used to create, fill and shorten the vectors of the storage of a simulation and of a fitted session.

CognitiveModeling.record_of_timestep — Method
record_of_timestep(parameters_valid, previous, cognitive_output, environment_output)

Return what a simulation returns as last_timestep for a timestep: for each model, whether its parameters stayed valid on it, and its state before the timestep and after it, with the cognitive model's at the top and the environment's under environment. parameters_valid is the flag of both models together, and with ValidByDefault, when no timestep can turn invalid, nothing is returned instead, so that nothing is collected. Used by collect_timestep_values.

CognitiveModeling.sample_output — Method
sample_output(rng, output_distribution)

Sample an output from what a model returned, using rand. Each output in a NamedTuple is sampled on its own, so a NamedTuple inside it gives a NamedTuple of samples, and an entry that is NoValue is kept. A number, a string or a symbol is a value and not something to sample from, and throws an ArgumentError which names Deterministic. Used on each timestep of a simulation, by simulate_timestep_both_models and simulate_timestep_one_model.

CognitiveModeling.simulate_all_timesteps — Function
simulate_all_timesteps(previous_timestep_values, who_starts, cognitive_model,
                       environment, cognitive_parameters, environment_parameters,
                       save_cognitive_trajectories, save_environment_trajectories,
                       observation_map, action_map, rng, timestep_sizes, n_steps,
                       save_initial_timestep_values::Val)

Simulate up to n_steps timesteps starting from previous_timestep_values, and return in a NamedTuple the vectors with what the simulated timesteps saved, under storage, the values of the last timestep that was kept, under last_kept_values, the number of timesteps that were kept, under n_timesteps, whether the parameters of both models stayed valid, under parameters_valid, under last_record the record of the last timestep that was simulated, from record_of_timestep with the timestep's number, and under masked whether the simulation was masked, as Val(true) or Val(false). The simulation stops before n_steps timesteps if stopping_criterion of either model is met, and none can be simulated if it is met already, which check_stopping_criterion_not_met makes an error. The simulation also stops when the parameters of either model turn invalid, and that timestep is left out, so that it is the last one simulated but not the last one kept. When save_initial_timestep_values is Val(true), each vector starts with what is saved from before the first timestep, as timestep 0.

A flag that must be masked, as masks_flag says, such as a traced Bool of a compiler like Reactant.jl, can't be branched on. From the first timestep with such a parameters_valid or stopping criterion, the simulation is masked instead of stopped, with simulate_remaining_timesteps_masked: every timestep is simulated and stored, and n_timesteps, parameters_valid and last_record say where the simulation ended, while last_kept_values is nothing. A stopping criterion that must be masked and is met before the first timestep isn't an error, but leaves no timestep kept.

previous_timestep_values and the last values kept are those of a timestep: the state and the action of the cognitive model, and under environment the state and the observation of the environment, each in its own names. When no timestep was kept, the last values kept are those of the first timestep, which turned invalid. The vectors are arranged as map_saved arranges them, with what save_cognitive_trajectories and save_environment_trajectories select.

simulate_session! continues from the values of the last timestep instead of from what was saved, because what is saved of a state can be a selection or a copy of it, and because the next simulation can change a state in place. Used by simulate_session and simulate_session!.

CognitiveModeling.simulate_remaining_timesteps — Method
simulate_remaining_timesteps(storage, timestep_values, who_starts, cognitive_model,
                             environment, cognitive_parameters, environment_parameters,
                             save_cognitive_trajectories, save_environment_trajectories,
                             observation_map, action_map, rng, timestep_sizes, n_steps,
                             offset)

Simulate the timesteps after the first, and return what simulate_all_timesteps returns. The simulation stops before n_steps timesteps if stopping_criterion of either model is met. It also stops when the parameters of either model turn invalid on a timestep, which is left out. From the first timestep whose stopping criterion or parameters_valid must be masked, as masks_flag says, the simulation continues with simulate_remaining_timesteps_masked instead. offset is 1 when the vectors start with timestep 0, and 0 otherwise, so that timestep t is element t + offset. Used by simulate_all_timesteps.

Masking, for flags that a compiler traces

CognitiveModeling.count_masked_timestep — Method
count_masked_timestep(masking, timestep_values, t)

Return what a masked simulation carries after timestep t, from masking, what it carried before it, as masking_after_first_timestep arranges it, and the values of the timestep, timestep_values. The timestep is the last simulated when the simulation was running before it, and it is kept when the parameters also stayed valid on it. Otherwise the simulation isn't running after it, the number of timesteps kept stays as it was, and the next timestep starts from the values the timestep started from, which select_values selects. Used by the masking loop.

source
CognitiveModeling.masking_after_first_timestep — Method
masking_after_first_timestep(timestep_values, stopped_before_first)

Return what a masked simulation carries after its first timestep, whose values are timestep_values, in a NamedTuple: whether it is still running, which it isn't when the stopping criterion was met before it, as stopped_before_first says, or the parameters turned invalid on it, whether the parameters stayed valid, under parameters_valid, the number of timesteps kept, under n_timesteps, the record of the last timestep simulated, under last_record, and the values that the next timestep starts from, under previous. The timesteps after a first timestep that didn't count start from its values, since the values from before it can have other types. Used by simulate_all_timesteps.

masking_before_timestep(timestep_values, t)

Return what a simulation that is masked from timestep t on carries before it, as masking_after_first_timestep arranges it: it is running, with valid parameters and the t - 1 timesteps before kept, the last of which has the values timestep_values. CognitiveModeling.select_values — Method
select_values(condition, values_if_true, values_if_false)

Return values_if_true when condition is true and values_if_false otherwise, selected with ifelse one number at a time, through NamedTuples, tuples and arrays, which must have the same layout in both. A value of a type that has a single value, such as NoValue, is the same in both and is returned as it is. Used by the masking loop, where condition can be a traced Bool, which nothing can branch on.

CognitiveModeling.simulate_remaining_timesteps_masked — Method
simulate_remaining_timesteps_masked(storage, masking, first_timestep, who_starts,
                                    cognitive_model, environment, cognitive_parameters,
                                    environment_parameters, save_cognitive_trajectories,
                                    save_environment_trajectories, observation_map,
                                    action_map, rng, timestep_sizes, n_steps, offset)

Simulate every timestep from first_timestep on, also those after the simulation ended, and return what simulate_all_timesteps returns, with masked=Val(true). It continues a simulation from the first timestep whose flag must be masked, as masks_flag says, such as the traced Bools of a compiler like Reactant.jl, which nothing can branch on: the parameters_valid of a model, or what its stopping_criterion returned.

Instead of stopping, the simulation carries masking, as masking_after_first_timestep arranges it, whose running flag turns false when the stopping criterion of either model is met before a timestep, or when the parameters of either model turn invalid on a timestep, and stays false. From then on, every timestep starts from the values of the last timestep that was kept, and nothing of it counts, as count_masked_timestep works out, so that n_timesteps, parameters_valid and last_record are what the stopping loop returns. The vectors in storage keep every timestep, so those after n_timesteps hold what the timesteps after the end gave, which belongs to no simulation. Used by simulate_all_timesteps and simulate_remaining_timesteps.

CognitiveModeling.starting_trajectories — Method
starting_trajectories(model, state, previous_output, save_trajectories)

Return the trajectories that an InstantiatedModel starts with: a TrajectoryHistory with what save_trajectories selects of where it starts, as timestep 0, and BeforeFirstTimestep as the size of the timestep, since none has been simulated yet. When nothing is selected, or save_trajectories doesn't save the initial timestep values, the vectors are empty.

A model hasn't received anything when it starts, so that entry has every input in the model's attributes as BeforeFirstTimestep(), and so has every output distribution. reset! starts from the same trajectories as the constructors.
