Types

CognitiveModeling.as_selection — Method
as_selection(names)

Return names as a selection, which is how a SaveTrajectories keeps it: SaveEverything as it is, and otherwise a Tuple of Symbols, as as_tuple makes it. Used by the constructor of SaveTrajectories.

source
CognitiveModeling.as_state_entries — Method
as_state_entries(states::Tuple)
as_state_entry(state)

Return the entries of a selection of states, as a SaveTrajectories keeps them, for states, and for one of them, state, in a tuple: a Symbol as it is, for a state that is saved whole, and :submodel => states as a Tuple of the name of the submodel and the selection of its states, from as_state_selection. A submodel with SaveEverything is saved whole, and one that nothing is selected of is left out. Anything else is a TypeError. Used by as_state_selection.

source
CognitiveModeling.as_state_selection — Method
as_state_selection(states)

Return states as the selection of states that a SaveTrajectories keeps: SaveEverything as it is, and otherwise a Tuple with an entry for each of them, as as_state_entries makes them: a Symbol for a state that is saved whole, and for a submodel that some states are saved of, a Tuple of its name and the selection of its states, in the same form. (:surprise, :perception => :expected_reward) is kept as (:surprise, (:perception, (:expected_reward,))). Used by the constructor of SaveTrajectories.

source
CognitiveModeling.state_selection_as_given — Method
state_selection_as_given(selection)
state_entry_as_given(entry)

Return the selection of states that a SaveTrajectories keeps, selection, and one entry of it, entry, in the form that they are given in: the states of a submodel as :submodel => states, from the tuple that as_state_selection keeps them as. Used to read save_trajectories.states, and to display a SaveTrajectories.

saves_nothing(save_trajectories)

Return whether save_trajectories selects nothing of any kind. Whether it saves the initial timestep values doesn't matter, since there is nothing to save of them. Used by simulate_session!, InstantiatedModel and fitted sessions, which save nothing at all then.

Selecting the values to save

CognitiveModeling.select_names — Method
select_names(x, selection::Val)

Return what a SaveTrajectories selects of x: x itself for SaveEverything, an empty NamedTuple for no names, and the named entries of a NamedTuple for a tuple of names. A selection with states of submodels, as as_state_selection keeps them, gives those under the names of their submodels, as select_states_of_submodels returns them. Used wherever something is saved, by simulations, instantiated models and fitted sessions.

source
CognitiveModeling.select_state_to_save — Method
select_state_to_save(model, state, selection::Val)

Return what is saved of state: what selection selects of the output of prepare_state_for_saving. When nothing is selected, the state isn't prepared at all, so that no copy is made of a state which isn't saved. Used wherever a state is saved, by simulations, instantiated models and fitted sessions.

source
CognitiveModeling.select_states_of_submodels — Method
select_states_of_submodels(state::NamedTuple, ::Val{selection})

Return what selection selects of state, where selection has states of submodels, as as_state_selection keeps them: each state that is selected whole under its name, and for each submodel a NamedTuple under its name with what is selected of its state, in the same way down through its submodels. Used by select_names.

source
CognitiveModeling.selected_state_name — Method
selected_state_name(entry)

Return the name of one entry of a selection of states: the state that is saved whole, or the submodel that some states are saved of, from the tuple that as_state_selection keeps them as, or from :submodel => states, as they are given. Used by state_selection_expression and check_state_selection_names.

source
CognitiveModeling.state_selection_expression — Method
state_selection_expression(state, selection::Tuple)

Return the expression of the NamedTuple with what selection selects of a state, which the expression state gives, or the expression of an error when selection has a name twice, which a NamedTuple can't have. Used while the code of select_states_of_submodels is generated.

Checking the names a SaveTrajectories selects

CognitiveModeling.check_savetrajectories_selection_names — Method
check_savetrajectories_selection_names(save_trajectories, model)

Throw an informative error if save_trajectories selects a state, an input, an output or an output distribution by name that isn't in the attributes of model, a cognitive model or an environment model, as get_attribute_names gives them with the name of the state of each submodel, since what is saved starts from those names, and prepare_state_for_saving returns a state with them. The states that it selects of a submodel are checked against the attributes of the submodel, as check_state_selection_names describes. Used by InstantiatedModel, simulate_session and SessionInfo, before anything is saved.

source
CognitiveModeling.check_selection_names — Method
check_selection_names(selection, names, kind, model)

Throw an informative error if selection has a name that isn't among names, those of kind in the attributes of model, where kind is "states", "inputs", "outputs" or "output distributions", the last being named like the outputs. SaveEverything can always be selected. Used by check_savetrajectories_selection_names for each kind.

source
CognitiveModeling.check_state_selection_names — Method
check_state_selection_names(selection, model, submodel_names)

Throw an informative error if the states that a SaveTrajectories selects of model, in selection, as save_trajectories.states gives them, aren't states in its attributes, as get_attribute_names gives them, if one is selected twice, or if states are selected of one that isn't the state of a submodel. The states that are selected of a submodel are checked against the submodel in the same way, down through its submodels, with submodel_names the names of the submodels that lead to model, which are none for the model of the SaveTrajectories itself. SaveEverything can always be selected. Used by check_savetrajectories_selection_names.

source
CognitiveModeling.state_of_submodel_hint — Method
state_of_submodel_hint(selected_names, names, model)

Return a sentence on how to select the first of selected_names that isn't among names, the states in the attributes of model, when it is a state of one of the submodels of model, and an empty string otherwise. Used by check_state_selection_names, for its error.

The sizes of the timesteps that are saved

CognitiveModeling.each_timestep_size — Method
each_timestep_size(timestep_sizes, n_steps)

Return the size of each of n_steps timesteps as a vector, for the trajectories of an instantiated model. A vector of sizes is returned as it is, and anything else is repeated for every timestep. Used by simulate_session!, for the sizes it adds to the trajectories of the instantiated models, and by saved_timestep_sizes.

source
CognitiveModeling.returned_timestep_sizes — Method
returned_timestep_sizes(timestep_sizes, n_timesteps, save_initial_timestep_values::Val)

Return the sizes of the n_timesteps timesteps that were simulated, as a simulation returns them. A vector of sizes is cut to those timesteps, since a model can stop a simulation early, and starts with BeforeFirstTimestep for timestep 0 when save_initial_timestep_values is Val(true), so that it has an element for each element of what is saved. Anything else is returned as it is, since it is the size of every timestep. Used by simulate_session, simulate_session! and saved_timestep_sizes.

source
CognitiveModeling.saved_timestep_sizes — Method
saved_timestep_sizes(timestep_sizes, n_steps, save_trajectories)

Return the sizes of n_steps timesteps as they are returned with what a session saves: one size for each timestep when save_trajectories saves anything, after BeforeFirstTimestep for timestep 0 when it saves the initial timestep values, and an empty vector when it saves nothing. Used by SessionInfo, for the sizes a fitted session returns.

Storing what is saved

CognitiveModeling.initialize_storage — Method
initialize_storage(first_value, n_steps)
initialize_storage(initial_value, first_value, n_steps)

Create the vector for saving one kind of value over n_steps timesteps, using the value of the first timestep to set its type. With initial_value, what is saved from before the first timestep, the vector starts with it, as timestep 0, and its type holds both. Used by simulations and by fitted sessions.

source
CognitiveModeling.push_value! — Method
push_value!(storage, value)

Add value at the end of storage, and return the vector. As for store_value!, a value that doesn't fit the type of storage moves the values so far to a wider vector, which is returned instead. Starting from Vector{Union{}}() lets the first value set the type. Used by fitted sessions.

source
CognitiveModeling.store_value! — Method
store_value!(storage, value, t)

Save value as element t of storage, and return the vector.

If the value doesn't fit the type of storage, the values so far are moved to a wider vector which can hold both types, and that vector is returned instead. Used by simulations and by fitted sessions.
