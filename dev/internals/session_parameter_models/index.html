CognitiveModeling.collect_parameters_in_session_order — Method
collect_parameters_in_session_order(parameters_by_session, session_ids)

Return the parameters of each session in parameters_by_session, as FixedSessionParametersBySession holds them, as one vector for each parameter with a value for every session, in the order of session_ids, with the parameters of each session found by parameters_of_session. A session with other parameters than the first is an error. Parameters that are already in the order of the sessions are returned as they are, after checking that each vector has a value for every session. Used by prepare_parameters_model, and by the models of FixedSessionParametersBySession in the inference backends.

has_vector_for_each_parameter(parameters_by_session)

Return whether parameters_by_session, as a FixedSessionParametersBySession holds it, gives the parameters in the order of the sessions, as a NamedTuple with one vector for each parameter, and not by the sessions' symbol names or identifiers. Used by parameter_names and collect_parameters_in_session_order.

CognitiveModeling.parameters_of_session — Method
parameters_of_session(parameters_by_session, session_id)

Return the parameters of the session with the identifier session_id in parameters_by_session: the entry under the session's symbol name, as session_id_to_symbol gives it, in a NamedTuple, and the entry under the identifier itself in a dictionary. A session without parameters is an error. Used by collect_parameters_in_session_order.

CognitiveModeling.AbstractRegressionTerm — Type
AbstractRegressionTerm

Supertype of the terms of a RegressionParameter: Intercept, ContinuousPredictor, CategoricalPredictor, Interaction and VaryingEffects. Each has its name in the field name, and each but VaryingEffects has its prior in the field prior.

CognitiveModeling.build_coefficients — Method
build_coefficients(sessions_info, terms, parameter_name, description)

Return the coefficients of terms, a NamedTuple with an intercept, predictors and interactions of description, such as "the regression of learning_rate", for the sessions in sessions_info, as a NamedTuple with the prior of each coefficient, priors, and the values it is multiplied by in every session, columns, both under the name of the coefficient and in the order of the terms, and with the reference level of each categorical predictor, reference_levels, under the names of the predictors. The coefficients of each term come from build_term_columns and build_interaction_columns, and must have names of their own. Used by build_regression_design and build_varying_effects_design.

source
CognitiveModeling.build_contrast_columns — Method
build_contrast_columns(sessions_info, predictor, parameter_name)

Return the coefficients of predictor, a CategoricalPredictor in the regression of the parameter parameter_name, in a NamedTuple with names, columns and reference_level: for each level other than the reference level, or for every level with the coding :full_dummy, in the order of their first session, the name of its coefficient and a vector with 1 for the sessions of that level and 0 for the others. The levels are the values of a single column, whose coefficients are named after the predictor and the level, as in diagnosis_clinical, or the NamedTuples of the values of several, whose coefficients are named by the symbol name of the level alone, as in diagnosis_clinical__site_2. With the coding :effects, the sessions of the reference level have -1 in every column. The reference level is the predictor's, or the level of the first session, and nothing with the coding :full_dummy. It is an error when there is one level only, and when the reference level isn't one of them. Used by build_term_columns.

source
CognitiveModeling.build_interaction_columns — Method
build_interaction_columns(interaction, columns_of_predictors, description)

Return the coefficients of interaction, an Interaction of description, such as "the regression of learning_rate", as build_term_columns returns those of a predictor: one for each combination of one coefficient of each of its predictors, whose coefficients are in columns_of_predictors under the names of the predictors, named after the coefficients it multiplies joined by _by_, with the product of their columns. The combinations are in the order of the coefficients of the first predictor, then of the second, and so on. A column that is zero in every session is an error, since no session informs its coefficient. Used by build_coefficients.

CognitiveModeling.build_regression_design — Method
build_regression_design(sessions_info, regression_parameter, parameter_name)

Return the design of the regression of the parameter parameter_name for the sessions in sessions_info, as HierarchicalRegressionSessionParameters keeps it in its field designs: the prior and the values of each coefficient of the intercept, the predictors and the interactions, from build_coefficients, and the design of the varying effects of each column, from build_varying_effects_design. Used by prepare_parameters_model.

CognitiveModeling.build_term_columns — Method
build_term_columns(sessions_info, term, parameter_name)

Return the coefficients of term, an Intercept or a predictor in the regression of the parameter parameter_name, for the sessions in sessions_info, as a NamedTuple with the name of each coefficient, names, and the values it is multiplied by in every session, columns: 1 for the intercept, the values of a continuous predictor, and the columns of the levels of a categorical predictor, from build_contrast_columns, with its reference_level. Used by build_coefficients.

source
CognitiveModeling.build_varying_effects_design — Method
build_varying_effects_design(sessions_info, varying_effects, parameter_name)

Return the design of varying_effects, a VaryingEffects of the regression of the parameter parameter_name, for the sessions in sessions_info, as HierarchicalRegressionSessionParameters describes it: the prior of the standard deviation of the deviations of each coefficient of their terms, with the prior under the symbol name of each group when the levels are grouped, the values that the deviations are multiplied by, from build_coefficients, the reference levels of their predictors, whether they are centered, and the levels of the sessions, from find_varying_effects_levels. The values of a coefficient other than the intercept must differ between the sessions of some level, or it is an error. Used by build_regression_design.

CognitiveModeling.collect_terms_by_name — Method
collect_terms_by_name(terms, description)

Return terms, the terms given to a RegressionParameter or to VaryingEffects, as a NamedTuple with each term under its name, after checking that each is an AbstractRegressionTerm, that their names differ, that there is one Intercept at most, and that each Interaction multiplies predictors among them. description says what was given the terms, such as "a RegressionParameter", for the errors. Used by the constructors of RegressionParameter and VaryingEffects.

CognitiveModeling.find_groups_of_levels — Method
find_groups_of_levels(sessions_info, group_by, level_of_each_session,
                      level_symbol_names, description)

Return the groups of the levels of varying effects by the values of the columns in group_by, a tuple of names, so that each group has a standard deviation of its own: a NamedTuple with the group of every level, group_of_each_level, the number of groups, n_groups, and the symbol name of each group, group_symbol_names, as group_sessions gives them for the sessions. Without columns it returns nothing, for one standard deviation. A level whose sessions are in more than one group is an error. description says what is grouped, for the errors, such as "the varying effects participant of learning_rate". Used by find_varying_effects_levels.

source
CognitiveModeling.find_varying_effects_levels — Method
find_varying_effects_levels(sessions_info, varying_effects, parameter_name)

Return the levels of varying_effects, a VaryingEffects of the regression of the parameter parameter_name, as a NamedTuple with the level of every session, level_of_each_session, the number of levels, n_levels, the symbol name of each level, level_symbol_names, and groups, from find_groups_of_levels. The levels are the values of a single column, or the combinations of the values of several, numbered in the order of their first session. Used by build_varying_effects_design.

name_of_columns(columns)

priors_of_groups(prior, groups)

varying_default_prior_field(term)

Return the name of the field of a DefaultRegressionPriors with the default prior of the standard deviation of term, a term of VaryingEffects: :varying_intercept for an Intercept, and :varying_slope for a predictor or an Interaction. Used by with_default_prior and check_has_prior.

CognitiveModeling.with_default_prior — Method
with_default_prior(term, default_priors)

Return term, a term given to a RegressionParameter, with the prior of its kind in default_priors, a DefaultRegressionPriors, when it has no prior, and VaryingEffects with the prior of the standard deviation of each of their terms that has none. Terms with a prior are returned as they are, and so is anything that isn't a term, for the constructor to report. Used by the constructor of RegressionParameter.

source
CognitiveModeling.with_default_settings — Method
with_default_settings(term, default_settings)

Return term, a term given to a RegressionParameter, with the settings in default_settings, a DefaultRegressionSettings, that it was given without: the coding of a CategoricalPredictor, and for VaryingEffects whether they are centered and the coding of their categorical predictors. A term's own settings are kept, and anything else is returned as it is. A reference level is an error when the default coding is :full_dummy, which has none. Used by the constructor of RegressionParameter.

CognitiveModeling.as_session_parameters_model — Method
as_session_parameters_model(parameters_model)

Return parameters_model as one session parameter model: a tuple of session parameter models as a CompositeSessionParameters of them, and a NamedTuple of them as a CompositeSessionParameters with each part under its name, which its variables are then named under. Anything else is returned as it is, for prepare_full_model to check. A tuple or a NamedTuple with something other than a session parameter model in it is an error. Used by prepare_full_model and by the functions of the inference backends that make a full model, such as turing_full_model.
