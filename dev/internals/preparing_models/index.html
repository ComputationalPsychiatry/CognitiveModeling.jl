Preparing a full model

CognitiveModeling.check_fixed_parameter_names — Method
check_fixed_parameter_names(fixed_parameters, model, keyword)

Throw an informative error if fixed_parameters, the values given with the keyword argument keyword, name a parameter that isn't in the attributes of model, a cognitive model or an environment model, from get_attribute_names, with those of its submodels, or if they are given for sessions without an environment, where model is NoEnvironment(). Used by with_fixed_parameters.

source
CognitiveModeling.check_given_parameters — Method
check_given_parameters(parameters_model, model, model_runs)

Throw an informative error if parameters_model, a parameter model, gives a parameter that isn't in the attributes of model, a cognitive model or an environment model, from get_attribute_names, with those of its submodels, or, when model_runs is true, doesn't give one in its attributes that has no default value in default_parameters of the model or of its submodels. For sessions without an environment, model is NoEnvironment(), and any parameter given is an error. Nothing is checked when parameter_names doesn't know the parameters. Used by prepare_full_model.

source
CognitiveModeling.check_is_parameters_model — Method
check_is_parameters_model(parameters_model)
check_is_downstream_model(downstream_model)

Throw an informative error if parameters_model isn't a subtype of AbstractParametersModel, such as the priors on their own, or if downstream_model isn't a subtype of AbstractDownstreamModel. Used by prepare_full_model.

source
CognitiveModeling.warn_if_saving_without_downstream_model — Method
warn_if_saving_without_downstream_model(sessions_info, downstream_model)

Warn when a session in sessions_info saves anything and downstream_model is NoDownstreamModel. Used by prepare_full_model.

source
CognitiveModeling.with_fixed_parameters — Method
with_fixed_parameters(parameters_model, fixed_parameters, model, keyword)

Return parameters_model, a parameter model, combined with the values in fixed_parameters, which every session gets for the parameters they name: a CompositeParameters of its parts, which keep their names, and a FixedParameters without a name, or parameters_model itself when no values are fixed. It is an error when a fixed parameter isn't in the attributes of model, and when parameters_model gives it too, which is checked here when parameter_names knows its parameters, and when the full model runs otherwise. keyword is the name of the keyword argument, for the errors. Used by prepare_full_model.

Preparing the data of a session

CognitiveModeling.check_columns_in_domains — Method
check_columns_in_domains(kind, columns, domains, in_table)

Check each value of each column in columns that has a domain in domains with check_value_in_domain, as a DataValue of kind, :observation or :action, at its index in the column. A column without a domain, a domain without a column, and a marker such as ImputedMissingValue or NoValue aren't checked. Used by check_data_in_domains.

source
CognitiveModeling.check_data_domains_fit_model — Method
check_data_domains_fit_model(model, domains, attribute)

Throw an ArgumentError if domains, what input_domains or output_domains returns for model, as attribute, :inputs or :outputs, says, isn't a NamedTuple of Domains, or names an input or an output that isn't in the model's attributes, from attribute_names. Used by check_data_in_domains.

source
CognitiveModeling.check_data_fits — Method
check_data_fits(cognitive_model, observations, actions)

Throw an informative error if the data of a session isn't a NamedTuple of vectors for the observations and one for the actions, doesn't have the observations and the actions in the cognitive model's attributes, from attribute_names, or has columns of different lengths, and return the number of timesteps otherwise. Used by SessionInfo.

source
CognitiveModeling.check_data_in_domains — Method
check_data_in_domains(cognitive_model, observations, actions, in_table)

Throw an ArgumentError if a value in observations or in actions, each a NamedTuple of vectors under the names of cognitive_model, is outside its domain: an observation outside the domain of its input in input_domains, and an action outside the domain of its output in output_domains, as check_value_in_domain checks them. Markers, such as ImputedMissingValue and NoValue, aren't checked. The error names the row of the table when in_table is true, and the timestep of the session otherwise. Used by SessionInfo, and by MultipleSessionsInfo for a whole table.

source
CognitiveModeling.check_environment_fits — Method
check_environment_fits(cognitive_model, environment, observations)

Throw an informative error if a session can't run with environment: without one, the observations in the data can't have an ImputedMissingValue, since nothing imputes it, and with one, its attributes must have the same observations and actions as those of cognitive_model. Used by SessionInfo.

source
CognitiveModeling.collect_values_to_condition_on — Method
collect_values_to_condition_on(columns)

Return the values to condition on of each action or observation in columns, a NamedTuple with one vector per name, as a NamedTuple of vectors in the order of the timesteps. Fitting scores these against the distributions the model gave on the same timesteps: the actions against the cognitive model's, and the observations against the environment's. Each vector has the element type of its column without ImputedMissingValue and the other markers, so that a session without values to condition on for a name gets an empty vector of the same type as other sessions, which scores nothing. A name whose column can only hold those markers is left out, which is decided by its type, so that it is the same for every session of a table. Used by SessionInfo, which keeps the results in its fields actions_to_condition_on and observations_to_condition_on.

source
CognitiveModeling.column_can_hold — Method
column_can_hold(column, missing_value)

Return whether column can hold missing_value, by its element type, or holds a value which is equal to it without having its type, such as -1.0 for -1, as isequal compares them. For a function, return whether column holds a value it returns true for. Used by mark_missing_values.

domains_function_name(attribute)

CognitiveModeling.is_missing_data_value — Method
is_missing_data_value(value, missing_values)

Return whether value is missing in the data: ImputedMissingValue itself, or matched by one of missing_values, as matches_missing_value says. Used by build_column, for a value which is built from several columns.

source
CognitiveModeling.map_to_environment_outputs — Method
map_to_environment_outputs(values, environment, observation_map, value_if_not_passed_on)

Return values, a NamedTuple in the names under which the cognitive model receives the observations, as environment gives them: under each output name in the environment's attributes, the value that observation_map passes on from it, or value_if_not_passed_on for an output that the map doesn't pass on. Without a map the names are the same. Without an environment values is returned as it is. Used by SessionInfo for the environment's data, with a column of the marker from marker_of_unmapped_outputs for each output that isn't passed on, and for the observation the environment starts from, with BeforeFirstTimestep.

source
CognitiveModeling.mark_missing_values — Method
mark_missing_values(columns, missing_values, impute)

Return columns, a NamedTuple with one vector per name, or a single vector, with every value which is matched by one of missing_values, as matches_missing_value says, replaced by the marker for a missing value: ImputedMissingValue when impute is true. When it is false, the marker is UnimputedMissingValue, which every ImputedMissingValue() that is in the data already becomes too. The arrays in the values that are kept are narrowed to the types they hold, by narrow_arrays_in_values.

A column gets the type of the marker in its element type when its element type allows one of the values, whether it holds one or not, so that sessions whose columns have the same types keep them, or when it holds a value equal to one of them of another type, such as -1.0 for -1, or a value that one of them, a function, returns true for. Any other column is kept as it is, after narrow_element_type. Anything that isn't a NamedTuple of vectors is returned as it is, for check_data_fits to report. Used by SessionInfo on the observations and the actions, and by build_column.

source
CognitiveModeling.marker_of_unmapped_outputs — Method
marker_of_unmapped_outputs(observations, actions)

Return the marker of the outputs of the environment that the observation map doesn't pass on, on every timestep of a session: SimulatedMissingValue when a column of observations or actions can hold one, so that they are simulated, and ImputedMissingValue otherwise, so that they are imputed. Used by SessionInfo, with map_to_environment_outputs.

source
CognitiveModeling.matches_missing_value — Method
matches_missing_value(missing_value, value)

Return whether value in the data stands for a missing one by missing_value, one of the values given for missing ones: whether missing_value returns true for value when it is a function, and whether the two are equal, as isequal compares them, otherwise. Used by is_missing_data_value and mark_missing_values.

source
CognitiveModeling.missing_value_marker — Method
missing_value_marker(impute)

Return the marker which the missing values in the data of a session become: ImputedMissingValue when they are imputed, and UnimputedMissingValue when impute is false. Used by mark_missing_values and build_column.

source
CognitiveModeling.narrow_arrays_in_values — Method
narrow_arrays_in_values(column)

Return column with the arrays in its values narrowed by narrow_parts, and its element type made to match them, keeping its other types, such as that of a marker. column itself is returned when no value changes, so that a column marked for a whole table keeps its element type in each session. Used by mark_missing_values and build_column.

source
CognitiveModeling.narrow_element_type — Method
narrow_element_type(column)

Return column with the types it holds as its element type, when its element type is Any or another abstract type that isn't a Union, and column itself otherwise. A vector written as [true, ImputedMissingValue(), true] has the element type Any, since only missing is promoted to a Union, and an Any in the data makes every timestep run with its types unknown. Used by mark_missing_values and build_column.

source
CognitiveModeling.narrow_parts — Method
narrow_parts(value)

Return value with each array in it narrowed to the types it holds, such as a Vector{Float64} for a Vector{Union{Missing,Float64}} without a missing element, and value itself when there is nothing to narrow. Used by narrow_arrays_in_values.

source
CognitiveModeling.value_passed_on — Method
value_passed_on(values, name, observation_map, value_if_not_passed_on)

Return the value in values that the environment's output name is received as: under the same name without a map, under the name observation_map gives it, or value_if_not_passed_on when the map doesn't pass it on. Used by map_to_environment_outputs.

CognitiveModeling.build_column — Method
build_column(table, specification, missing_values, impute)

Return the column of an attribute for every row of table, as columns_used describes the specification, with the values that are missing replaced by their marker, as mark_missing_values does: the column itself, or one built row by row from several, where a missing value in any of them makes the whole value of the row missing, and whose arrays are narrowed as narrow_arrays_in_values does. The column is made for the whole table, so that every session gets the same element type. Used by build_columns.

source

build_columns(table, columns, missing_values, impute)

Return the columns in columns, a NamedTuple from the name the model uses to the specification of the column in table, for every row of the table, as a NamedTuple with the model's names, each built with build_column. Used by MultipleSessionsInfo when it splits a table.

CognitiveModeling.check_table — Method
check_table(table, columns)

CognitiveModeling.column_entry — Method
column_entry(entry)

Return the name the model uses for an attribute and the specification of its column, as a pair, from one entry of the columns of a kind. An entry is a name, for a column that is named as the model names the attribute, or a pair from the specification of the column to the model's name: :outcome => :reward for a column with another name, (:choicecol, :rtcol) => :ssm_action or (; choice = :choicecol, rt = :rtcol) => :ssm_action for a value built from several columns, and (:choicecol, :rtcol) => combine => :ssm_action for what a function gives for their values. Used by column_map.

source
CognitiveModeling.column_map — Method
column_map(columns, cognitive_model, kind)

Return the columns of kind, an AbstractObservableAttributeKind, as a NamedTuple from the name the model uses to the specification of the column, from what observation_columns or action_columns of MultipleSessionsInfo was given:

  • a tuple or a vector with an entry for each attribute, see column_entry: a name, for a column that is named as the model names the attribute, or a pair from the specification of the column to the model's name, such as :outcome => :reward;
  • one such pair on its own;
  • a single name, which is the column of the attribute of that kind when the model has only one in its attributes, whatever the column is called. It is an error when the model has several, and when the model's attributes have the name as one of the other kind only, since observation_columns and action_columns may then be swapped. When its attributes have none of that kind, it is a column of that name;
  • how to build a value from several columns, without the model's name: a NamedTuple of names, or a pair of a tuple of names and a function, for the attribute of that kind when the model has only one in its attributes.

A specification is the name of a column, or how to build one from several, see columns_used. Used by MultipleSessionsInfo when it splits a table.

source
CognitiveModeling.columns_used — Method
columns_used(specification)

Return the names of the columns of a table that one specification of an attribute's column uses, as a tuple. A specification is one of:

  • a Symbol, the column itself;
  • a NamedTuple of Symbols, such as (; choice = :choicecol, rt = :rtcol), for a column of NamedTuples with those names built from the columns, one for each row;
  • a Tuple of Symbols, such as (:choicecol, :rtcol), for a column of Tuples;
  • a Pair of a Tuple of Symbols and a function, such as (:choicecol, :rtcol) => (choice, rt) -> [choice, rt], for a column with what the function gives for the values of each row.

Used by MultipleSessionsInfo when it checks a table, and by build_column.

CognitiveModeling.named_data — Method
named_data(data, cognitive_model, kind)

Return the data of kind, an AbstractObservableAttributeKind, as a NamedTuple of vectors: a single vector as the data of the attribute of that kind when the model has only one in its attributes, which is an error when it has another number of them, and anything else as it is, for check_data_fits to check. Including the environment in a session, or leaving it out

CognitiveModeling.decide_whether_environment_is_included — Method
decide_whether_environment_is_included(include_environment, environment, observations,
                                       actions, save_environment_trajectories)

Return whether a session includes its environment, as the include_environment of SessionInfo says: always with true, which needs an environment, never with false, and with nothing only when an observation or an action is ImputedMissingValue or SimulatedMissingValue, or the environment's trajectories are saved. A session without an environment never includes one. With false, it is an error when an observation is ImputedMissingValue() or the environment's trajectories are saved, since those need the environment. Used by prepare_session.

Reading the columns that a parameter model uses

CognitiveModeling.group_sessions — Method
group_sessions(sessions_info, group_by, reader)

Return the groups of the sessions in sessions_info by the values of the columns in group_by, a tuple of names: a NamedTuple with the group of every session, group_of_each_session, the number of groups, n_groups, and the symbol name of each group, group_symbol_names, made from its values as session_id_to_symbol makes the symbol name of a session from its data identifier. Groups are numbered in the order of their first session, and with no columns every session is in one group. A session with more than one value, or a missing value, in one of the columns is an error, which starts with reader, as for read_level_of_each_session. Used by prepare_parameters_model, for the groups of a HierarchicalGroupedParameters and for the varying effects of a HierarchicalRegressionParameters.

source
CognitiveModeling.read_level_of_each_session — Method
read_level_of_each_session(sessions_info, columns, reader)

Return the level of every session of sessions_info in the columns in columns, a tuple of names, as a vector in the order of the sessions: its value of a single column, or a NamedTuple of its values of several. Each value is read with read_one_value_of_each_session, whose errors start with reader. Used by group_sessions and by the categorical predictors of a HierarchicalRegressionParameters.

source
CognitiveModeling.read_one_value_of_each_session — Method
read_one_value_of_each_session(sessions_info, column, reader)

Return the value of column in every session of sessions_info, as a vector in the order of the sessions, from the table that the sessions were split from. A session with more than one value in the column, or with a missing one, is an error, which starts with reader, a description of what reads the column, such as "HierarchicalGroupedParameters groups learning_rate by". Used by read_level_of_each_session and by the continuous predictors of a HierarchicalRegressionParameters.
