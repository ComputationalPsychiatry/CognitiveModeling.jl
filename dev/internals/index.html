CognitiveModeling.AbstractModel — Type
AbstractModel

Supertype for cognitive models and environment models, which the functions that treat the two in the same way take. A model is a subtype of AbstractCognitiveModel or of AbstractEnvironmentModel, and not of this type itself.

CognitiveModeling.collect_initial_outputs — Method
collect_initial_outputs(save_initial_values::Val, previous_outputs, cognitive_model,
                        environment, observation_map, action_map, save_history,
                        save_environment_history)

Return what is saved from before the first timestep, as timestep 0, in a NamedTuple with the names of the saved outputs of collect_timestep_outputs, or nothing when save_initial_values is Val(false).

The observation and the action are the previous ones, as each side receives them, the action distributions are BeforeFirstTimestep for every action, since none was given yet, and the states are the states before the first timestep. They must be saved before the first timestep runs, since it can change a state in place.

CognitiveModeling.collect_timestep_outputs — Method
collect_timestep_outputs(environment_output, cognitive_output,
                         observation_from_environment, observation, action,
                         action_to_environment, cognitive_model, environment,
                         save_history, save_environment_history)

Collect the outputs of a timestep in a NamedTuple, each both as it is, which the next timestep starts from, and as it is saved, which save_history and save_environment_history select.

observation_from_environment is the observation sampled from what the environment gave, and observation is the same observation as the cognitive model receives it. action_to_environment is action as the environment receives it. Each pair differs when a NameMap selects or renames them. The cognitive model's history holds the observation as the cognitive model receives it, and the environment's the action as the environment does.

This is its own function so that if an output can have two types, like an observation with an entry that is sometimes NoObservation, the compiler can split the call and get a concrete type for each.

CognitiveModeling.run_remaining_timesteps — Method
run_remaining_timesteps(storage, outputs, who_starts, cognitive_model, environment,
                        cognitive_parameters, environment_parameters, save_history,
                        save_environment_history, observation_map, action_map, rng,
                        timestep_sizes, n_steps, offset)

Run the timesteps after the first, and return the NamedTuple of vectors with the saved outputs of the timesteps that ran, followed by the outputs of the last one. The timesteps end before n_steps if stopping_criterion of environment is met. offset is 1 when the vectors start with timestep 0, and 0 otherwise, so that timestep t is element t + offset.

This is its own function so that it's compiled for the types of the first outputs.

source
CognitiveModeling.run_timesteps — Method
run_timesteps(previous_outputs, who_starts, cognitive_model, environment,
              cognitive_parameters, environment_parameters, save_history,
              save_environment_history, observation_map, action_map, rng,
              timestep_sizes, n_steps, save_initial_values::Val)

Run up to n_steps timesteps starting from previous_outputs, and return a NamedTuple of vectors with the saved outputs of the timesteps that ran, followed by the outputs of the last one. The timesteps end before n_steps if stopping_criterion of environment is met, and an environment where it is met already can't run any. When save_initial_values is Val(true), each vector starts with what is saved from before the first timestep, as timestep 0.

The vectors are observations, actions, cognitive_states and environment_states, as save_history and save_environment_history select them, and observations_from_environment and actions_to_environment with what save_environment_history selects of the observations the environment gave and the actions it received, for the environment's history.

simulate! continues from the last outputs instead of from what was saved, because prepare_state_for_saving can return anything, and because the next simulation can change a state in place.

CognitiveModeling.timestep — Method
timestep(cognitive_model, observation, previous_cognitive_state, previous_action,

Run a timestep of cognitive_model on observation, without an environment, and return the action sampled from its output, its new state, and what save_history selects of the observation, the action and the state, in a NamedTuple. The observation must have the names that cognitive_model lists.

CognitiveModeling.columns_used — Method
columns_used(specification)

Return the names of the columns of a table that one specification of an attribute's column uses, as a tuple. A specification is one of:

  • a Symbol, the column itself;
  • a NamedTuple of Symbols, such as (; choice = :choicecol, rt = :rtcol), for a column of NamedTuples with those names built from the columns, one for each row;
  • a Tuple of Symbols, such as (:choicecol, :rtcol), for a column of Tuples;
  • a Pair of a Tuple of Symbols and a function, such as (:choicecol, :rtcol) => (choice, rt) -> [choice, rt], for a column with what the function gives for the values of each row.

A missing in any column used makes the value of that row missing. Used by MultipleSessionsInfo when it checks a table, and by build_column.

CognitiveModeling.entry — Method
entry(::Val{name}, value)

Return (; name = value), built in a call of its own, so that a value which can have two types gives one of two NamedTuples with a concrete field each, as (; a = x) written out doesn't: Julia infers that as a NamedTuple whose field type is the Union, which nothing is compiled for, while a call with a Union-typed argument is split by type. CognitiveModeling.recorded_actions — Method
recorded_actions(actions)

Return the recorded values of each action in actions, a NamedTuple with one vector per action, as a NamedTuple of vectors in the order of the timesteps. Fitting scores these against the model's action distributions on the same timesteps. Each vector has the element type of its column without MissingValue and NoAction, so that a session without recorded values for an action gets an empty vector of the same type as other sessions, which scores nothing. An action whose column can only hold those markers is left out, which is decided by its type, so that it is the same for every session of a table. Used by SessionInfo, which keeps the result in its field recorded.

recorded_on_timestep(data_action, action_distribution, cognitive_model)

Return whether each action of one timestep has a recorded value in the data, as a NamedTuple of Bools with the names of data_action. CognitiveModeling.replace_missing — Method
replace_missing(columns, replacement)

Return columns, a NamedTuple with one vector per name, with every missing replaced by replacement: MissingValue for a value that wasn't recorded, or NoAction or NoObservation for nothing happening on that timestep. A column whose element type allows missing gets the replacement in its element type whether it holds a missing or not, so that the sessions of one table all have the same type, and a column whose element type doesn't is kept as it is, after narrow_column. Anything that isn't a NamedTuple of vectors is returned as it is, for check_data to report. Used by SessionInfo on the observations and the actions.

CognitiveModeling.row — Method
row(columns, t)

Return the NamedTuple of the values at timestep t of columns, a NamedTuple of vectors with one entry for each timestep, built with entry so that a column which holds two types, such as an action that is MissingValue on some timesteps, gives one of two NamedTuples with concrete fields rather than one without a definite type. It is unrolled over the names, which it takes from the type. Used by the Turing.jl models of a timestep and of several sessions, which reads the parameters of one session with it.

CognitiveModeling.rows_per_session — Method
rows_per_session(table, id_columns)

Return a vector with one pair for each session in table: its identifier, and the indices of its rows. CognitiveModeling.warn_if_environment_is_unused — Method
warn_if_environment_is_unused(session_info)
warn_if_environment_is_unused(sessions)

Warn if a session, or every session in a vector of them, has an environment model but no observation that is MissingValue, since filling those in is all an environment does in a session, so it only costs time. The environment is kept as given, since leaving it out would change the variables of a model whose environment samples. Used by the constructors of SessionInfo and MultipleSessionsInfo.

CognitiveModeling.without_missing_actions — Method
without_missing_actions(actions)

Return actions, a NamedTuple with one vector per action, with every MissingValue replaced by NoAction, for a session where a missing action is passed on as an action that wasn't taken instead of being imputed. Used by SessionInfo when impute_missing_actions is false.
